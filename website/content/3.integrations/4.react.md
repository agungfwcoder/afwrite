There is no separate React package: copy this component (~35 lines) into your project. It is built on [`create()`](/integrations/javascript), so you get the full UI.

```bash [Terminal]
npm install github:agungfwcoder/afwrite#semver:^2
```

```jsx [Afwrite.jsx]
import { useEffect, useRef } from 'react';
import { create } from 'afwrite';
import 'afwrite/style.css';

// <Afwrite value={html} onChange={setHtml} options={{ lang: 'en', upload }} />
export function Afwrite({ value = '', onChange, options }) {
  const host = useRef(null);
  const editor = useRef(null);
  const onChangeRef = useRef(onChange);
  onChangeRef.current = onChange;

  useEffect(() => {
    const instance = create(host.current, { ...options, content: value });
    instance.on('change', ({ html }) => onChangeRef.current?.(html));
    editor.current = instance;
    return () => {
      instance.destroy();
      editor.current = null;
    };
  }, []); // opsi dibaca sekali saat dipasang

  // Nilai dari luar -> editor (dilewati bila isinya sama, agar kursor tidak melompat).
  useEffect(() => {
    const instance = editor.current;
    if (!instance) return;
    const current = instance.getHTML();
    if (value !== current && instance.editor.normalizeHTML(value) !== current) instance.setHTML(value);
  }, [value]);

  // React tidak merender isi div ini; isinya milik afwrite.
  return <div ref={host} />;
}
```

## Usage

```jsx
import { useState } from 'react'
import { Afwrite } from './Afwrite'

export function PostForm() {
  const [body, setBody] = useState('<p>Hello</p>')
  return (
    <form onSubmit={(e) => { e.preventDefault(); save(body) }}>
      <Afwrite value={body} onChange={setBody} options={{ upload: uploadImage }} />
      <button>Save</button>
    </form>
  )
}
```

- **Two-way**: typing calls `onChange`; changing `value` from outside updates the editor. Equal content (even if written differently) is skipped, so the cursor doesn't jump.
- **StrictMode**: React mounts, unmounts, and mounts again in development. `destroy()` restores the element, so you still end up with exactly one editor.
- **Options** are read once on mount. To change them, remount the component, e.g. with `key`.
- **Don't render children** inside the wrapper's `<div>`: its content belongs to the editor.

::note
Tested from a separate Vite + React 18 app (production build) in Chrome, Firefox, and Safari (WebKit): StrictMode, two-way value, slash menu, and unmount/remount. Not yet tested with server rendering (Next.js); keep the wrapper in a Client Component (`'use client'`).
::
