The integration files live in the `integrations/laravel` folder of the :brand repo. Copy them into your Laravel project using the same folder structure:

| File | Purpose |
|---|---|
| `app/Support/WyswygHtml.php` | Server-side HTML sanitization, same whitelist as the editor |
| `app/Http/Controllers/WyswygUploadController.php` | Image uploads from the editor |
| `resources/views/components/wysiwyg.blade.php` | The `<x-wysiwyg>` component |
| `resources/js/wyswyg.js` | Loads afwrite + an upload function with the CSRF token |
| `tests/Feature/WyswygTest.php` | Feature tests for all three |

Tested with Laravel 13, Livewire 4, and `ezyang/htmlpurifier`.

::steps{level="2"}

## Install

```bash [Terminal]
npm install github:agungfwcoder/afwrite#semver:^2 alpinejs
composer require ezyang/htmlpurifier
php artisan storage:link
```

Import `resources/js/wyswyg.js` from `resources/js/app.js`. Without Livewire, start Alpine yourself:

```js [resources/js/app.js]
import Alpine from 'alpinejs'
import './wyswyg'

window.Alpine = Alpine
Alpine.start()
```

With Livewire, `import './wyswyg'` is all you need (see [Livewire](/integrations/livewire)). Make sure your layout includes the CSRF token:

```blade [layouts/app.blade.php]
<meta name="csrf-token" content="{{ csrf_token() }}">
@vite(['resources/css/app.css', 'resources/js/app.js'])
```

## Upload route

```php [routes/web.php]
use App\Http\Controllers\WyswygUploadController;

Route::post('/wyswyg/upload', WyswygUploadController::class)
    ->middleware('auth')
    ->name('wyswyg.upload');
```

The controller only accepts PNG, JPG, GIF, WebP, and AVIF (SVG is rejected), stores the file on the `public` disk, and returns `{ "url": "..." }`. If you track images in a media library, also return `"mediaId"`: the editor stores it as `<img data-media-id="...">`. The field name can be changed, e.g. `window.wyswygUpload(url, { field: 'file' })`.

## Form

```blade
<form method="POST" action="{{ route('posts.update', $post) }}">
    @csrf
    @method('PUT')

    <x-wysiwyg
        name="body"
        :value="$post->body"
        upload-url="{{ route('wyswyg.upload') }}"
        autosave="post-{{ $post->id }}"
        :headings="[2, 3, 4]"
    />

    <button>Save</button>
</form>
```

## Save with sanitization

```php
use App\Support\WyswygHtml;

public function update(Request $request, Post $post)
{
    $data = $request->validate(['body' => ['required', 'string']]);
    $post->update(['body' => WyswygHtml::clean($data['body'])]);

    return back();
}
```

### Title & slug (article mode)

With `title-name="title"`, the title is submitted as a separate field. Generate the final slug on the server, including making it unique:

```blade
<x-wysiwyg name="body" :title="true" title-name="title" />
```

```php
use Illuminate\Support\Str;

$data = $request->validate(['title' => ['required', 'string', 'max:200'], 'body' => ['required', 'string']]);

$slug = Str::slug($data['title']) ?: Str::random(8); // non-Latin titles can produce an empty slug
$base = $slug;
for ($i = 2; Post::where('slug', $slug)->whereKeyNot($post->id)->exists(); $i++) {
    $slug = "{$base}-{$i}";
}
```

## `<x-wysiwyg>` props

| Prop | Description |
|---|---|
| `name` | Required. Form field name |
| `value` | Initial content; after a failed validation, the `old()` value is used automatically |
| `lang` | `en` (default) or `id` |
| `placeholder` | Text shown when empty |
| `upload-url` | Upload route URL |
| `autosave` | localStorage draft key |
| `:toolbar="false"` | No top toolbar |
| `:readonly="true"` | Read-only mode |
| `format` | `html` or `json` |
| `:headings="[2, 3, 4]"` | Heading levels to enable |
| `:title="true"` | Article mode: `<h1>` title + subtitle |
| `:formats="['underline', 'align']"` | Extra formats to enable (all by default, except in article mode); `:formats="false"` = none |
| `title-name="title"` | Submits the title (first text / article `<h1>`) as a `title` input |

Other attributes (e.g. `class`) are passed through to the editor element. The initial content is sanitized on the server before it's printed, because raw HTML on the page would be executed by the browser before the editor gets a chance to filter it.

::caution
Requests can be sent without going through the editor, so you **must** call `WyswygHtml::clean()` before saving. The result is safe to print with `{!! !!}`.
::

`WyswygHtml::clean()` allows all editor output, including the extra formats (`u`, `s`, `span[style=color]`, `mark[style=background-color]`, `afw-align-*` classes) and `img[data-media-id]`. HTMLPurifier writes styles slightly differently (`color:#e11d48;`); the editor normalizes them again when the content is loaded, so `getHTML()` before saving and after reloading stays identical.
