There is no separate Vue package: copy this component (~35 lines) into your project. It is built on [`create()`](/integrations/javascript), so you get the full UI.

```bash [Terminal]
npm install github:agungfwcoder/afwrite#semver:^2
```

```vue [Afwrite.vue]
<script setup>
// <Afwrite v-model="html" :options="{ lang: 'en', upload }" />
import { onBeforeUnmount, onMounted, ref, watch } from 'vue';
import { create } from 'afwrite';
import 'afwrite/style.css';

const props = defineProps({ modelValue: { type: String, default: '' }, options: { type: Object, default: () => ({}) } });
const emit = defineEmits(['update:modelValue']);
const host = ref(null);
let editor = null; // bukan ref(): instance tidak boleh dibungkus Proxy reaktif Vue

onMounted(() => {
  editor = create(host.value, { ...props.options, content: props.modelValue });
  editor.on('change', ({ html }) => emit('update:modelValue', html));
});

// Nilai dari luar -> editor (dilewati bila isinya sama, agar kursor tidak melompat).
watch(() => props.modelValue, (value) => {
  if (!editor) return;
  const current = editor.getHTML();
  if (value !== current && editor.editor.normalizeHTML(value) !== current) editor.setHTML(value);
});

onBeforeUnmount(() => editor?.destroy());
</script>

<template>
  <div ref="host" />
</template>
```

## Usage

```vue
<script setup>
import { ref } from 'vue'
import Afwrite from './Afwrite.vue'

const body = ref('<p>Hello</p>')
</script>

<template>
  <Afwrite v-model="body" :options="{ upload: uploadImage }" />
</template>
```

- **`v-model`**: typing updates `body`; changing `body` updates the editor. Equal content (even if written differently) is skipped, so the cursor doesn't jump.
- **Keep the instance out of `ref()`**: the editor holds DOM and ProseMirror state that must not be wrapped in Vue's reactive Proxy, which is why the wrapper uses a plain `let`.
- **Options** are read once on mount. To change them, remount the component, e.g. with `:key`.

::note
Tested from a separate Vite + Vue 3.5 app (production build) in Chrome, Firefox, and Safari (WebKit): `v-model` both ways, slash menu, and `v-if` unmount/remount. With Nuxt, mount it client-side only: wrap it in `<ClientOnly>`, or `import('afwrite')` inside `onMounted` as the live editors on this site do.
::
