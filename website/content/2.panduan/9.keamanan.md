Semua HTML yang masuk (paste, drop, `setHTML`) dan keluar (`getHTML`) melewati whitelist:

| Jenis | Yang diizinkan |
|---|---|
| Tag | `p`, `h1` (mode artikel), `h2`–`h6` (sesuai `headings`), `blockquote`, `ul`, `ol`, `li`, `b`, `i`, `a`, `code`, `br`, `pre`, `figure`, `img`, `figcaption`, `iframe`, `hr`; dengan [format tambahan](/panduan/toolbar#format-tambahan) juga `u`, `s`, `span`, `mark` |
| `a[href]` | http, https, mailto, tel, dan URL relatif |
| `img[src alt data-media-id]` | src divalidasi; data URL hanya PNG/JPG/GIF/WebP/AVIF; `data-media-id` hanya angka |
| `class` | `afw-subtitle` (subjudul mode artikel) dan `afw-align-center/right/justify` pada `p` & `h2`–`h6` |
| `style` | Hanya `color` pada `span` dan `background-color` pada `mark`, dengan warna dari palet |
| `figure` | `data-size` (`wide`/`full`), `data-embed` |
| `iframe` | Hanya YouTube/Vimeo, `src` dibangun ulang dari ID video |

Paste dari Word, Google Docs, dan web dibersihkan: style, class, dan tag asing dibuang, tetapi tebal/miring dari style tetap dikenali.

::caution
**Sanitasi di browser tidak menggantikan sanitasi di server.** Request bisa dikirim tanpa melewati editor, jadi server wajib menyaring HTML sebelum menyimpan atau menampilkannya, dengan whitelist yang sama.
::

Untuk Laravel tersedia `WyswygHtml::clean()` berbasis HTMLPurifier. Lihat [Integrasi Laravel](/integrasi/laravel).

## Extension sendiri

Node atau mark milik aplikasi dipasang lewat opsi `extensions`. Tag dan atributnya perlu ditambahkan ke whitelist lewat `sanitize`, karena semua yang tidak ada di whitelist dibuang:

```js
import { Mark } from '@tiptap/core'

const Sup = Mark.create({
  name: 'sup',
  parseHTML: () => [{ tag: 'sup' }],
  renderHTML: () => ['sup', 0],
})

wysiwyg({
  extensions: [Sup],
  sanitize: {
    allowTags: ['sup'],                       // tag inline tambahan
    allowAttributes: { a: ['target', 'rel'] }, // per tag; '*' = semua tag
    allowClasses: ['catatan'],
  },
})
```

Atribut `on*`, `style`, dan `srcdoc` tidak pernah lolos, sedangkan `href`/`src` tetap divalidasi. Atribut atau class pada tag bawaan (mis. `rel` pada link) juga butuh extension yang menyimpannya, misalnya lewat `addGlobalAttributes`. Whitelist server (`WyswygHtml::clean()`) perlu ditambah dengan aturan yang sama.

## Memakai `sanitize()` langsung

```js
import { sanitize } from 'afwrite'

sanitize('<div style="x">Hai <script>x()</script><b>kamu</b></div>') // '<p>Hai <b>kamu</b></p>'
sanitize('<h4>Bab</h4>', { headings: [2, 3, 4] })                   // '<h4>Bab</h4>'
```
