Semua HTML yang masuk (paste, drop, `setHTML`) dan keluar (`getHTML`) melewati whitelist:

| Jenis | Yang diizinkan |
|---|---|
| Tag | `p`, `h1` (mode artikel), `h2`–`h6` (sesuai `headings`), `blockquote`, `ul`, `ol`, `li`, `b`, `i`, `a`, `code`, `br`, `pre`, `figure`, `img`, `figcaption`, `iframe`, `hr` |
| `a[href]` | http, https, mailto, tel, dan URL relatif |
| `img[src alt]` | src divalidasi; data URL hanya PNG/JPG/GIF/WebP/AVIF |
| `p[class]` | Hanya `afw-subtitle` (subjudul mode artikel) |
| `figure` | `data-size` (`wide`/`full`), `data-embed` |
| `iframe` | Hanya YouTube/Vimeo, `src` dibangun ulang dari ID video |

Paste dari Word, Google Docs, dan web dibersihkan: style, class, dan tag asing dibuang, tetapi tebal/miring dari style tetap dikenali.

::caution
**Sanitasi di browser tidak menggantikan sanitasi di server.** Request bisa dikirim tanpa melewati editor, jadi server wajib menyaring HTML sebelum menyimpan atau menampilkannya, dengan whitelist yang sama.
::

Untuk Laravel tersedia `WyswygHtml::clean()` berbasis HTMLPurifier. Lihat [Integrasi Laravel](/integrasi/laravel).

## Memakai `sanitize()` langsung

```js
import { sanitize } from 'wyswyg'

sanitize('<div style="x">Hai <script>x()</script><b>kamu</b></div>') // '<p>Hai <b>kamu</b></p>'
sanitize('<h4>Bab</h4>', { headings: [2, 3, 4] })                   // '<h4>Bab</h4>'
```
