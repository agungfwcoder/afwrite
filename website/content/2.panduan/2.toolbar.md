## Judul H2–H6

Bawaan editor memakai **H2** dan **H3**. Aktifkan level lain dengan `headings`:

```html
<div x-data="wysiwyg({ headings: [2, 3, 4, 5, 6] })"></div>
```

Opsi ini otomatis mengatur:

| Bagian | Perilaku |
|---|---|
| Toolbar | Tombol untuk setiap level aktif |
| Bubble | Paling banyak 2 level pertama, agar tetap ringkas |
| Slash menu `/` | Item untuk setiap level aktif |
| Shortcut | Ctrl/⌘ + Alt + 2 … 6 (hanya level aktif) |
| Markdown | `## ` … `###### ` lalu spasi |
| Paste & konten lama | Level yang tidak aktif diturunkan ke level aktif terdekat (H1 menjadi level terkecil) |

::wyswyg-demo
---
options:
  headings: [2, 3, 4, 5, 6]
  stats: false
content: |
  <h2>Judul 2</h2><h3>Judul 3</h3><h4>Judul 4</h4><h5>Judul 5</h5><h6>Judul 6</h6>
---
::

::note
Contoh pemetaan dengan `headings: [2, 4]`: H3 menjadi H2, H5 dan H6 menjadi H4.
::

## Susunan tombol sendiri

`toolbarItems` dan `bubbleItems` berisi **grup** tombol; setiap grup dipisah garis tipis.

```js
wysiwyg({
  toolbarItems: [
    [{ command: 'bold', shortcut: '⌘B' }, { command: 'italic', shortcut: '⌘I' }],
    [{ command: 'h2', shortcut: '⌘⌥2' }, { command: 'h4', shortcut: '⌘⌥4' }],
    [{ command: 'ul', shortcut: '⌘⇧8' }],
  ],
  headings: [2, 4],
})
```

`command` adalah nama perintah dari [Perintah & shortcut](/panduan/perintah); `shortcut` hanya teks petunjuk di tooltip.

::warning
Tombol judul hanya bekerja untuk level yang aktif di `headings`.
::

Untuk memakai susunan bawaan tetapi dengan level judul lain, gunakan helper `withHeadings`:

```js
import { TOOLBAR, BUBBLE, withHeadings } from 'wyswyg'

wysiwyg({
  headings: [2, 3, 4],
  toolbarItems: withHeadings(TOOLBAR, [2, 3, 4]),
  bubbleItems: withHeadings(BUBBLE, [2, 3]),
})
```

## Slash menu

`blocks` mengatur isi slash menu. Contoh tanpa video dan blok kode:

```js
import { BLOCKS } from 'wyswyg'

wysiwyg({ blocks: BLOCKS.filter((b) => !['embed', 'codeblock'].includes(b.command)) })
```

## Menyembunyikan UI

| Opsi | Efek |
|---|---|
| `toolbar: false` | Tanpa toolbar atas (ala Medium) |
| `bubble: false` | Tanpa bubble saat teks diblok |
| `slash: false` | Tanpa slash menu |
| `stats: false` | Tanpa jumlah kata |
