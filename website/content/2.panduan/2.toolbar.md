## Judul H2–H6

Bawaan editor memakai **H2** dan **H3**, tampil sebagai tombol **T** besar dan **t** kecil seperti Medium (berlaku setiap kali tepat dua level aktif; tiga level atau lebih memakai ikon H2, H3, …). Aktifkan level lain dengan `headings`:

```html
<div x-data="wysiwyg({ headings: [2, 3, 4, 5, 6] })"></div>
```

Opsi ini otomatis mengatur:

| Bagian | Perilaku |
|---|---|
| Toolbar | Tombol untuk setiap level aktif |
| Bubble | Paling banyak 2 level pertama, agar tetap ringkas |
| Slash menu `/` | Item untuk setiap level aktif |
| Shortcut | Ctrl/⌘ + Alt + 2 … 6 (hanya level aktif) |
| Markdown | `## ` … `###### ` lalu spasi |
| Paste & konten lama | Level yang tidak aktif diturunkan ke level aktif terdekat (H1 menjadi level terkecil) |

::editor-demo
---
options:
  headings: [2, 3, 4, 5, 6]
  stats: false
content: |
  <h2>Judul 2</h2><h3>Judul 3</h3><h4>Judul 4</h4><h5>Judul 5</h5><h6>Judul 6</h6>
---
::

::note
Contoh pemetaan dengan `headings: [2, 4]`: H3 menjadi H2, H5 dan H6 menjadi H4.
::

## Format tambahan

Mode **Lengkap** (toolbar) dan **Sederhana** (`toolbar: false`) membawa format berikut. Mode artikel (`title: true`) tidak, agar tetap polos ala Medium.

| Format | Tombol | Shortcut | Output |
|---|---|---|---|
| Garis bawah | toolbar & bubble | Ctrl/⌘ + U | `<u>` |
| Coret | toolbar | Ctrl/⌘ + Shift + X | `<s>` |
| Warna teks | palet **Warna & stabilo** | | `<span style="color: #e11d48">` |
| Stabilo | palet **Warna & stabilo** | | `<mark style="background-color: #fef08a">` |
| Perataan | palet **Perataan** | Ctrl/⌘ + Shift + L / E / R / J | `<p class="afw-align-center">` (juga `right`, `justify`) |

::editor-demo
---
options:
  stats: false
content: |
  <h2 class="afw-align-center">Judul di tengah</h2>
  <p>Teks <u>bergaris bawah</u>, <s>dicoret</s>, <span style="color: #e11d48">merah</span>, dan <mark style="background-color: #fef08a">distabilo</mark>.</p>
  <p class="afw-align-right">Paragraf rata kanan.</p>
---
::

- Warna hanya dari palet (opsi `colors` dan `highlights`) dan selalu ditulis sebagai hex, sehingga HTML sebelum disimpan dan sesudah dimuat ulang identik. Warna di luar palet dibuang; stabilo di luar palet menjadi `<mark>` polos.
- Perataan berlaku untuk paragraf dan judul tingkat teratas, bukan isi list atau kutipan. Rata kiri = tanpa class.
- Konten lama ikut terbaca: `ql-align-*` (Quill), `style="text-align: …"`, atribut `align`, `<strike>`, `<del>`, `<ins>`, `<font color>`, dan `<mark data-color>`.
- Atur sebagian saja: `formats: ['underline', 'align']`, atau `formats: false` untuk mematikan semua. Tombol yang formatnya tidak aktif tidak ditampilkan, termasuk di `toolbarItems`/`bubbleItems` sendiri.

```js
wysiwyg({
  formats: ['underline', 'color', 'align'],
  colors: ['#e11d48', '#2563eb', '#16a34a'],
})
```

::note
Di halaman publik, `.afw-prose` sudah memuat gaya `afw-align-*`, `<u>`, `<s>`, dan `<mark>`.
::

## Mode artikel (judul & subjudul)

Seperti editor Medium: teks paling atas selalu **judul**, baris tepat di bawahnya bisa dijadikan **subjudul**. Di atas judul hanya boleh gambar, video, atau pemisah; gambar pertama menjadi **gambar utama** (feature image).

```html
<div x-data="wysiwyg({ name: 'body', title: true, toolbar: false })"></div>
```

::editor-demo
---
options:
  title: true
  toolbar: false
  stats: false
---
::

- **Judul** (`<h1>`) selalu ada di baris pertama, berisi teks polos. Enter pindah ke baris di bawahnya.
- **Subjudul** dibuat dengan memilih tombol judul **kecil** (level kedua, mis. H3) di bubble atau toolbar pada baris tepat setelah judul, atau lewat `/Subjudul`. Pilih lagi untuk mengembalikannya menjadi paragraf. Di baris lain, tombol yang sama tetap membuat judul bagian biasa.
- Tebal, miring, list, dan kode tidak berlaku di judul/subjudul; tombolnya tampil redup. Link tetap bisa di subjudul.
- [Format tambahan](#format-tambahan) (garis bawah, warna, perataan) tidak aktif di mode artikel. Aktifkan manual dengan `formats` jika memang perlu.
- Label **Judul / Subjudul** tampil di margin kiri setelah judul/subjudul berisi tulisan, jika editor cukup lebar (≥ 640px).
- Paste beberapa baris ke judul: baris pertama menjadi judul, sisanya menjadi isi di bawahnya.
- **Di atas judul**: klik `+` (atau ketik `/`) di judul yang masih kosong lalu pilih Gambar, Video, atau Pemisah, atau tempel / seret gambar ke judul. Bloknya dipasang tepat di atas judul dan kursor tetap di judul. Boleh lebih dari satu; teks tidak bisa berada di atas judul.

Output HTML:

```html
<figure><img src="cover.jpg" alt=""></figure>  <!-- opsional: gambar/video/pemisah di atas judul -->
<h1>Judul tulisan</h1>
<p class="afw-subtitle">Subjudul opsional</p>
<p>Isi tulisan…</p>
```

Konten tanpa `<h1>` di awal tetap aman dimuat: judul kosong ditambahkan dan isi lama tidak bergeser. Gambar/video/pemisah di awal konten tetap di atas judul hanya jika langsung diikuti `<h1>`.

Untuk kartu pratinjau / meta tag, `getMeta()` mengambil data seperti preview cerita di Medium:

```js
editor.getMeta()
// { image: { src, alt, caption, mediaId } | null, title: 'Judul tulisan', subtitle: 'Subjudul opsional', slug }
```

`title` = teks pertama, `subtitle` = teks kedua (subjudul, atau paragraf pertama jika tidak ada), `image` = gambar pertama. Berlaku juga tanpa mode artikel.

::tip
Font judul bisa dibedakan, mis. serif seperti Medium: `.afw, .afw-prose { --afw-font-title: Georgia, serif; }`
::

## Susunan tombol sendiri

`toolbarItems` dan `bubbleItems` berisi **grup** tombol; setiap grup dipisah garis tipis.

```js
wysiwyg({
  toolbarItems: [
    [{ command: 'bold', shortcut: '⌘B' }, { command: 'italic', shortcut: '⌘I' }],
    [{ command: 'h2', shortcut: '⌘⌥2' }, { command: 'h4', shortcut: '⌘⌥4' }],
    [{ command: 'ul', shortcut: '⌘⇧8' }],
  ],
  headings: [2, 4],
})
```

`command` adalah nama perintah dari [Perintah & shortcut](/panduan/perintah); `shortcut` hanya teks petunjuk di tooltip.

::warning
Tombol judul hanya bekerja untuk level yang aktif di `headings`.
::

Tombol `color` dan `align` membuka palet (warna & stabilo, perataan), bukan langsung menjalankan perintah.

Untuk memakai susunan bawaan tetapi dengan level judul lain, gunakan helper `withHeadings`:

```js
import { TOOLBAR, BUBBLE, withHeadings } from 'afwrite'

wysiwyg({
  headings: [2, 3, 4],
  toolbarItems: withHeadings(TOOLBAR, [2, 3, 4]),
  bubbleItems: withHeadings(BUBBLE, [2, 3]),
})
```

## Slash menu

`blocks` mengatur isi slash menu. Contoh tanpa video dan blok kode:

```js
import { BLOCKS } from 'afwrite'

wysiwyg({ blocks: BLOCKS.filter((b) => !['embed', 'codeblock'].includes(b.command)) })
```

## Menyembunyikan UI

| Opsi | Efek |
|---|---|
| `toolbar: false` | Tanpa toolbar atas (ala Medium) |
| `bubble: false` | Tanpa bubble saat teks diblok |
| `slash: false` | Tanpa slash menu |
| `stats: false` | Tanpa jumlah kata |
