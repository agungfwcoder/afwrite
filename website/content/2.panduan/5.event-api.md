## Event Alpine

Dikirim dari elemen editor dan *bubbling*, jadi bisa ditangkap di elemen induk:

```html
<div x-data="wysiwyg()" @wysiwyg-change="body = $event.detail.html"></div>
```

| Event | `detail` |
|---|---|
| `wysiwyg-ready` | `{ editor }` |
| `wysiwyg-change` | `{ html, meta }`, dengan `meta` hasil `getMeta()` |
| `wysiwyg-focus` / `wysiwyg-blur` | |
| `wysiwyg-error` | `{ message, error? }` |

## Judul & slug

Event `wysiwyg-change` membawa `meta`, jadi judul dan slug bisa dipakai langsung, mis. untuk pratinjau URL:

```html
<form method="post" x-data="{ slug: '', edited: false }"
      @wysiwyg-change="if (!edited) slug = $event.detail.meta.slug">
  <input name="slug" x-model="slug" @input="edited = true">
  <div x-data="wysiwyg({ name: 'body', title: true, titleName: 'title' })"></div>
</form>
```

`slugify()` juga bisa dipakai sendiri:

```js
import { slugify } from 'afwrite'   // CDN: window.Afwrite.slugify

slugify('Café Pagi, Ayo!')          // 'cafe-pagi-ayo'
slugify('Judul panjang…', { maxLength: 60 })
```

::caution
Slug dari browser hanya **pratinjau**. Huruf non-Latin (Arab, Mandarin, …) menghasilkan slug kosong, dan keunikan hanya bisa dicek di server. Buat slug final di server, lihat [Integrasi Laravel](/integrasi/laravel#judul-slug-mode-artikel).
::

## Method komponen Alpine

Dipanggil dari markup di dalam komponen, atau lewat `Alpine.$data(el)`:

| Method | Keterangan |
|---|---|
| `getHTML()` / `setHTML(html)` | Ambil / ganti isi (selalu disanitasi) |
| `getJSON()` / `setJSON(doc)` | Isi sebagai JSON dokumen ProseMirror |
| `getMeta()` | Pratinjau ala Medium: `{ image, title, subtitle, slug }` dari gambar pertama, teks pertama, dan teks kedua |
| `exec(perintah, ...arg)` | Jalankan perintah |
| `isActive(perintah)` | Format aktif di posisi kursor |
| `setReadOnly(bool)` | Ubah mode baca saja |
| `focus()` | Fokus ke akhir editor |
| `editor()` | Instance `Editor` |

## API `Editor`

| Method | Keterangan |
|---|---|
| `exec(nama, ...arg)`, `isActive(nama)`, `state()` | Perintah & status format |
| `getHTML()`, `setHTML(html, { resetHistory })`, `getJSON()`, `setJSON(doc)`, `getText()`, `clear()`, `isEmpty()` | Isi |
| `insertHTML(html)`, `insertText(teks)`, `paste({ html, text, files })`, `insertImages(files)` | Sisipkan |
| `undo()`, `redo()`, `canUndo()`, `canRedo()` | Riwayat |
| `restoreDraft()`, `discardDraft()`, `clearDraft()`, `draft` | Autosave |
| `setReadOnly(bool)`, `focus()`, `stats()` | Lainnya |
| `on(event, fn)` → fungsi untuk berhenti, `off()`, `destroy()` | Event |

Event `Editor`: `change`, `state`, `selection`, `slash`, `history`, `readonly`, `linkrequest`, `embedrequest`, `error`, `focus`, `blur`.

```js
const editor = Alpine.$data(el).editor()
const stop = editor.on('change', (html) => console.log(html))
editor.paste({ html: '<p>Halo <b>dunia</b></p>' }) // aturan sama seperti paste sungguhan
stop()
```

## Akses Tiptap

Instance Tiptap tersedia di `editor.tiptap` untuk kebutuhan lanjutan:

```js
editor.tiptap.commands.selectAll()
editor.tiptap.state.doc.childCount
```

::note
Perubahan lewat `editor.tiptap` tetap memicu event `change`, tetapi output tetap dibatasi whitelist sanitasi.
::

## Tanpa Alpine

Inti editor bisa dipakai sendiri, tanpa UI melayang (link dan video memakai `prompt()` bawaan browser):

```js
import { Editor } from 'afwrite'
import 'afwrite/style.css'

const editor = new Editor(document.querySelector('#editor'), { lang: 'en' })
editor.on('change', (html) => (input.value = html))
document.querySelector('#bold').onclick = () => editor.exec('bold')
```

Elemen `#editor` perlu dibungkus elemen ber-class `afw` agar style berlaku.
