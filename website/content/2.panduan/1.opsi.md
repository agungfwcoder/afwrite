```html
<div x-data="wysiwyg({ name: 'body', lang: 'id', headings: [2, 3, 4], autosave: 'post-42' })"></div>
```

## Form & isi

::field-group
  ::field{name="name" type="string"}
  Nama `<input type="hidden">` yang dibuat untuk form. Bawaan `''` (tanpa input).
  ::

  ::field{name="format" type="'html' | 'json'"}
  Isi input hidden. Bawaan `'html'`. Dengan `'json'`, isinya JSON dokumen ProseMirror (lihat [JSON](/panduan/json)).
  ::

  ::field{name="content" type="string"}
  Konten awal. Bawaan: isi elemen editor di HTML.
  ::

  ::field{name="autosave" type="string | { key, delay }"}
  Simpan draf ke localStorage. Bawaan `null`. Lihat [Autosave](/panduan/autosave).
  ::

  ::field{name="readonly" type="boolean"}
  Mode baca saja. Bawaan `false`.
  ::
::

## Tampilan & UI

::field-group
  ::field{name="toolbar" type="boolean"}
  Toolbar di atas. Bawaan `true`; `false` = hanya bubble (ala Medium).
  ::

  ::field{name="bubble" type="boolean"}
  Bubble toolbar saat teks diblok. Bawaan `true`.
  ::

  ::field{name="stats" type="boolean"}
  Jumlah kata & waktu baca di bawah editor. Bawaan `true`.
  ::

  ::field{name="dragHandle" type="boolean"}
  Pegangan ⋮⋮ di kiri blok untuk memindah (seret) atau memilih (klik) blok. Bawaan `true`. Hanya tampil di perangkat dengan mouse.
  ::

  ::field{name="toolbarItems / bubbleItems" type="array"}
  Susunan tombol sendiri. Lihat [Toolbar & menu](/panduan/toolbar).
  ::

  ::field{name="title" type="boolean"}
  Mode artikel ala Medium: judul `<h1>` + subjudul. Bawaan `false`. Lihat [Toolbar & menu](/panduan/toolbar#mode-artikel-judul-subjudul).
  ::

  ::field{name="headings" type="number[]"}
  Level judul yang dipakai, `2`–`6`. Bawaan `[2, 3]`. Lihat [Toolbar & menu](/panduan/toolbar#judul-h2h6).
  ::

  ::field{name="blocks" type="array"}
  Isi slash menu `/`. Bawaan: semua blok.
  ::

  ::field{name="lang" type="'id' | 'en'"}
  Bahasa antarmuka. Bawaan `'id'`.
  ::

  ::field{name="strings" type="object"}
  Timpa sebagian teks, mis. `{ placeholder: 'Tulis…' }`. Daftar kunci ada di `src/i18n.js`.
  ::

  ::field{name="placeholder" type="string"}
  Teks saat editor kosong. Bawaan dari bahasa.
  ::

  ::field{name="label" type="string"}
  `aria-label` area editor untuk pembaca layar.
  ::
::

## Perilaku

::field-group
  ::field{name="markdown" type="boolean"}
  Shortcut markdown saat mengetik. Bawaan `true`.
  ::

  ::field{name="slash" type="boolean"}
  Slash menu. Bawaan `true`.
  ::

  ::field{name="pasteAsPlainText" type="boolean"}
  Buang semua format saat paste. Bawaan `false`.
  ::

  ::field{name="historyLimit" type="number"}
  Jumlah langkah undo. Bawaan `100`.
  ::
::

## Gambar

::field-group
  ::field{name="upload" type="(file: File) => Promise<string>"}
  Fungsi upload yang mengembalikan URL gambar. Tanpa ini gambar disimpan sebagai base64 di HTML.
  ::

  ::field{name="maxImageSize" type="number"}
  Batas ukuran gambar dalam byte. Bawaan 5 MB; `0` = tanpa batas.
  ::

  ::field{name="allowDataImages" type="boolean"}
  Izinkan `<img src="data:image/…">` di output. Bawaan `true`.
  ::
::
