## Menambahkan gambar

- Ketik `/gambar` atau klik `+` lalu pilih **Gambar**
- Seret file gambar ke dalam editor
- Tempel screenshot atau gambar yang disalin

Format yang diterima: PNG, JPG, GIF, WebP, AVIF. Selama upload, pratinjau langsung tampil dengan indikator.

## Upload ke server

Tanpa opsi `upload`, gambar disimpan sebagai **base64** di dalam HTML. Untuk produksi, berikan fungsi yang mengirim file dan mengembalikan URL:

```js
async function uploadImage(file) {
  const body = new FormData()
  body.append('image', file)
  const res = await fetch('/upload', { method: 'POST', body })
  if (!res.ok) throw new Error('Upload gagal')
  return (await res.json()).url
}
```

```html
<div x-data="wysiwyg({ name: 'body', upload: uploadImage, maxImageSize: 2 * 1024 * 1024 })"></div>
```

Fungsi upload juga boleh mengembalikan objek. `mediaId` (ID di media library aplikasi, hanya angka) disimpan di gambar:

```js
upload: async (file) => {
  // ...kirim file...
  return { url: '/storage/a.jpg', mediaId: 42, alt: '' } // alt opsional
}
```

```html
<figure><img src="/storage/a.jpg" alt="" data-media-id="42"><figcaption>Gambar 1</figcaption></figure>
```

Nilainya ikut di `getMeta().image.mediaId`, misalnya untuk menjadikan gambar di isi artikel sebagai gambar utama. Nilai yang bukan angka dibuang.

Jika upload gagal atau file terlalu besar, gambar dibatalkan dan pesan tampil di toast (event `wysiwyg-error`). Untuk Laravel, controller upload sudah tersedia di [Integrasi Laravel](/integrasi/laravel).

## Mengatur gambar

Klik gambar untuk memunculkan toolbar media:

| Tombol | Fungsi |
|---|---|
| Normal / Lebar / Penuh | Ukuran tampilan (`data-size="wide"` / `"full"`) |
| Alt text | Deskripsi untuk pembaca layar |
| Hapus | Menghapus gambar (juga Backspace/Delete) |

Keterangan (caption) diketik langsung di bawah gambar.

## Video

Ketik `/video` lalu tempel link, atau **tempel link YouTube/Vimeo di baris kosong**. Video YouTube memakai domain `youtube-nocookie.com`, dan alamat iframe selalu dibangun ulang dari ID video, tidak pernah dari URL mentah.

## Pemisah

Ketik `--- ` atau `/pemisah`. Klik celah kosong di sekitar pemisah atau gambar untuk menambahkan baris baru di sana.

## API

```js
editor.insertImages(files)       // File[] atau FileList
editor.selectedMedia()           // { kind: 'image' | 'embed' | 'divider', size, alt } atau null
editor.setMediaSize('wide')      // media yang sedang dipilih
editor.setMediaAlt('Pemandangan gunung')
editor.removeMedia()
```
