Selain HTML, isi editor bisa disimpan sebagai JSON dengan format dokumen ProseMirror/Tiptap, sehingga bisa dibaca alat-alat dari ekosistem yang sama.

```js
editor.getJSON()
// { type: 'doc', content: [
//   { type: 'heading', attrs: { level: 2 }, content: [{ type: 'text', text: 'Judul' }] },
//   { type: 'paragraph', content: [
//     { type: 'text', text: 'Halo ' },
//     { type: 'text', marks: [{ type: 'bold' }], text: 'dunia' } ] } ] }

editor.setJSON(doc)
```

## Di form

```html
<div x-data="wysiwyg({ name: 'body', format: 'json' })"></div>
```

Input hidden `body` berisi string JSON.

## Struktur

| Node | Keterangan |
|---|---|
| `paragraph`, `heading` (`attrs.level`), `blockquote` | Blok teks |
| `bulletList`, `orderedList`, `listItem` | List (item berisi `paragraph` dan list bertingkat) |
| `codeBlock` | Blok kode |
| `horizontalRule` | Pemisah |
| `image` (`src`, `alt`, `size`) | Gambar; isinya teks keterangan |
| `embed` (`provider`, `id`, `size`) | Video YouTube/Vimeo |
| `hardBreak`, `text` | Inline |

Mark: `bold`, `italic`, `code`, `link` (`attrs.href`).

## Tanpa editor

```js
import { toJSON, fromJSON } from 'afwrite'

toJSON('<p>Halo</p>', { headings: [2, 3, 4] })
fromJSON(doc, { headings: [2, 3, 4] })
```

`fromJSON` membuang node/mark yang tidak dikenal dan selalu menyanitasi hasilnya, jadi JSON dari sumber tak dipercaya tetap aman.

::warning
Format JSON v1 (`blocks` + rentang `marks`) tidak didukung lagi sejak v2. Format HTML tidak berubah.
::
