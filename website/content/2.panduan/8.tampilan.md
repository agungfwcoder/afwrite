## Variabel CSS

Semua warna, font, dan ukuran memakai variabel `--afw-*`:

```css
.afw, .afw-prose {
  --afw-accent: #e11d48;
  --afw-font-content: Georgia, serif;
  --afw-content-size: 1.25rem;
  --afw-quote-style: italic; /* kutipan miring (bawaan: normal) */
}
```

## Tema gelap

```html
<div data-afw-theme="dark" x-data="wysiwyg()"></div>
<article class="afw-prose" data-afw-theme="auto">…</article>
```

`"auto"` mengikuti pengaturan sistem (`prefers-color-scheme`).

::note
Jika `.afw-prose` diberi `x-ignore`, binding Alpine pada elemen itu sendiri (mis. `:data-afw-theme`) ikut tidak berjalan. Tulis atributnya langsung atau pasang lewat JavaScript.
::

## Tipografi hasil

Class `afw-prose` memberi tipografi yang sama dengan editor:

```blade
<article class="afw-prose">{!! $post->body !!}</article>
```

Media ukuran penuh di `.afw-prose` melebar keluar sebesar `--afw-prose-bleed` (bawaan `0`).

## Tidak bentrok dengan framework

Semua class memakai prefix `afw-`, variabel `--afw-*`, dan atribut `data-afw-*`. Gaya editor ditulis eksplisit sehingga tidak berubah oleh reset Bootstrap 5 atau Tailwind; hal ini diuji otomatis.

## Bahasa

```js
wysiwyg({ lang: 'en', strings: { placeholder: 'Write your story…', bold: 'Strong' } })
```

## Layout sendiri

Sediakan elemen `data-afw-editor` di dalam komponen; markup UI bawaan tidak akan disuntikkan dan Anda bebas menyusun toolbar sendiri:

```html
<div x-data="wysiwyg({ name: 'body' })">
  <div class="toolbar-saya">
    <button type="button" @mousedown.prevent @click="exec('bold')" :class="{ aktif: isActive('bold') }">B</button>
  </div>
  <div data-afw-editor x-ignore></div>
</div>
```
