---
title: Autosave
description: Menyimpan draf ke localStorage dan memulihkannya.
navigation:
  icon: i-lucide-save
---

```html
<div x-data="wysiwyg({ name: 'body', autosave: 'post-42' })"></div>
```

- Draf disimpan ke localStorage setiap ada perubahan, dengan jeda 1 detik.
- Saat halaman dibuka lagi dan ada draf yang berbeda dari isi saat ini, muncul banner **Pulihkan / Buang**. Selama belum dipilih, draf lama tidak ditimpa.
- Draf dihapus otomatis saat form induknya dikirim.

Gunakan kunci yang unik per dokumen, mis. `post-{{ $post->id }}`, agar draf tidak tertukar.

## Mengatur jeda

```js
wysiwyg({ autosave: { key: 'post-42', delay: 3000 } })
```

## Lewat API

```js
editor.draft          // { html, time } atau null
editor.restoreDraft()
editor.discardDraft()
editor.clearDraft()   // mis. setelah berhasil disimpan lewat AJAX
```

::note
Jika localStorage tidak tersedia (mode privat, kuota penuh), autosave diam-diam tidak aktif tanpa error.
::
