Perintah dijalankan lewat `exec(nama, ...argumen)` dan dipakai juga oleh tombol toolbar:

```html
<button @click="exec('bold')">Tebal</button>
```

## Daftar perintah

| Perintah | Shortcut | Markdown |
|---|---|---|
| `bold` / `italic` | Ctrl/⌘ + B / I | `**teks**` / `*teks*` atau `_teks_` |
| `link` | Ctrl/⌘ + K | tempel URL di atas teks terseleksi |
| `unlink` | | |
| `h2` … `h6` | Ctrl/⌘ + Alt + 2 … 6 | `## ` … `###### ` (level harus aktif di `headings`) |
| `paragraph` | Ctrl/⌘ + Alt + 0 | |
| `quote` | Ctrl/⌘ + Shift + 9 | `> ` |
| `ul` / `ol` | Ctrl/⌘ + Shift + 8 / 7 | `- ` / `1. ` |
| `indent` / `outdent` | Tab / Shift + Tab (di dalam list) | |
| `codeblock` | Ctrl/⌘ + Alt + C | ```` ``` ```` + spasi, `/kode` |
| `image` | | `/gambar`, seret file, tempel screenshot |
| `embed` | | `/video`, tempel link YouTube di baris kosong |
| `hr` | | `--- ` |
| `undo` / `redo` | Ctrl/⌘ + Z / Ctrl/⌘ + Shift + Z (atau Ctrl + Y) | |

`` `kode` `` (kode inline) dibuat lewat markdown.

::tip
Shortcut blok markdown (`##`, `>`, `-`, …) hanya berlaku di awal paragraf biasa, bukan di dalam list atau kutipan.
::

## Argumen perintah

```js
editor.exec('link', 'https://example.com') // tanpa argumen: UI meminta URL
editor.exec('embed', 'https://youtu.be/dQw4w9WgXcQ')
editor.exec('image', fileList)              // tanpa argumen: dialog pilih file
```

URL link divalidasi: `example.com` menjadi `https://example.com`, sedangkan `javascript:` dan `data:` ditolak.

## Keyboard di blok khusus

**Blok kode**: Enter = baris baru, Tab / Shift + Tab = indentasi, Enter di baris kosong terakhir = keluar dari blok, paste selalu sebagai teks.

**Gambar, video, atau pemisah yang dipilih**: Backspace/Delete menghapus, Enter membuat paragraf baru di bawahnya, panah keluar dari media.

**Keterangan gambar**: Enter pindah ke paragraf setelah gambar.

**Judul atau kutipan kosong**: Enter mengubahnya kembali menjadi paragraf.
