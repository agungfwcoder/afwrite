## Good editors usually come with a bill

When I went looking for a rich text editor for my own projects, I kept running into the same thing: the editors that felt good to write in were paid. Either the whole editor needed a plan, or the basics were free and the features I actually needed sat behind a subscription, a license key, or a usage limit.

I just wanted to write the way Medium lets you write: a clean page, a toolbar that only shows up when you select text, `/` to add a block, and HTML that is safe to store. I did not want to pay every month for that.

## So I built one and made it free

:brand is the editor I wanted. **Every feature is free**, and there is no paid version:

- **No Pro tier.** The bubble toolbar, slash menu, article mode with title and slug, images and video, drag and drop, autosave, JSON output, and the Laravel integration are all in the same free package.
- **No license key and no account.** Install it from GitHub or load it from the CDN and it works.
- **No usage limits.** Use it in as many projects, sites, and editors as you like.
- **MIT license.** Use it in personal and commercial projects, change it, and ship it.

## Built on open source

:brand stands on [Tiptap](https://tiptap.dev) and [ProseMirror](https://prosemirror.net), which are free and open source too. The [credits page](/more/credits) lists everything it uses.

## How you can help

:brand stays free, so it is not funded by sales. If it helps you, you can give back in other ways:

- Star the repository on [GitHub](https://github.com/agungfwcoder/afwrite).
- Report bugs or ideas in [Issues](https://github.com/agungfwcoder/afwrite/issues).
- Tell other developers who are still paying for an editor.
