## Commands

```bash [Terminal]
npm install
npm run dev            # demo at http://localhost:5173
npm run build          # dist/
npm test               # unit tests (Vitest)

npx playwright install chromium firefox webkit   # one-time
npm run test:browser                             # browser tests in Chromium
npm run test:browser -- all                      # Chromium, Firefox, WebKit
```

Laravel integration: `php artisan test --filter=WyswygTest` in a Laravel project that already includes the files from `integrations/laravel`.

## Documentation site

This site lives in the `website/` folder (Nuxt UI Docs). Its demos use the library source directly from `src/`, so library changes show up immediately.

```bash [Terminal]
cd website
npm install
npm run dev            # http://localhost:3000
```

Pages are written in Markdown in `website/content/`. Interactive editors are embedded with the `editor-demo` component:

```mdc
::editor-demo
---
options:
  headings: [2, 3, 4]
content: |
  <h2>Title</h2><p>Initial content</p>
---
::
```

## Repo structure

```
src/
  core/        editor core (Tiptap engine: schema, commands, sanitization, media, markdown)
  afwrite.js   create(): the UI in plain JavaScript (toolbar, bubble, slash menu, media toolbar, ...)
  ui/          UI markup, DOM helpers, positioning of floating elements
  alpine.js    Alpine component: a thin adapter over create()
  i18n.js      English & Indonesian strings
  icons.js     icons and default toolbar layout
  style.css    all CSS (afw prefix)
demo/          demo page
examples/      React & Vue wrappers (not part of the package)
integrations/  Laravel integration (Blade, upload, server sanitization)
tests/         unit tests (Vitest) & browser tests (Playwright)
website/       documentation site (Nuxt)
```
