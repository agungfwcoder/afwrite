## General

### Is it really free?

Yes. Every feature is in the same MIT-licensed package: no Pro tier, no license key, no account, and no usage limits. You can use it in commercial projects too. See [Why afwrite](/more/why).

### What is it built on?

[Tiptap](https://tiptap.dev) and [ProseMirror](https://prosemirror.net), with a Medium-style UI on top written in plain JavaScript, plus a thin [Alpine.js](https://alpinejs.dev) component.

### How big is it?

About 135 KB gzip in total, of which ~110 KB is Tiptap + ProseMirror. If only an admin panel uses the editor, [load it dynamically](/getting-started/installation#size) so other pages don't ship it.

### Can I try it before installing?

Yes, on the [demo page](/getting-started/demo).

## Frameworks

### Do I need Alpine.js?

No. The full UI (bubble toolbar, slash menu, `+` button, toasts) is plain JavaScript: call [`create(el, options)`](/integrations/javascript). On Alpine pages, `x-data="wysiwyg()"` adds `x-model` and automatic cleanup on top.

### Can I use it with React, Vue, or Svelte?

Yes. There are small, tested wrappers for [React](/integrations/react) and [Vue](/integrations/vue) to copy into your project (no separate package). For Svelte or anything else, call [`create()`](/integrations/javascript) on mount and `destroy()` on unmount.

### Does it work with Laravel and Livewire?

Yes. There is a [Laravel integration](/integrations/laravel) with a Blade component, an upload controller, and server-side sanitization, plus a guide for [Livewire 3/4](/integrations/livewire) including `wire:navigate`.

### Will it clash with Bootstrap or Tailwind?

No. Everything uses the `afw-` class prefix, `--afw-*` variables, and `data-afw-*` attributes, and the editor styles are written so framework resets don't affect them. See [Appearance](/guide/appearance#no-clashes-with-frameworks).

## Content

### Should I store HTML or JSON?

Store **HTML** if you mostly display the content on web pages: it is ready to print inside `.afw-prose` after server-side sanitization. Store **JSON** (`format: 'json'`) if you want to process the content as structured data or use it with other Tiptap/ProseMirror tools. See [JSON](/guide/json).

### Do I still need to sanitize on the server?

**Yes, always.** The editor filters everything in the browser, but anyone can send a request without going through the editor. Clean the HTML on the server with the same whitelist before you store or print it. For Laravel, use `WyswygHtml::clean()`. See [Security](/guide/security).

### How do I display the saved content?

Wrap it in the `afw-prose` class so it gets the same typography as the editor:

```blade
<article class="afw-prose">{!! $post->body !!}</article>
```

### Can I add my own tags or blocks?

Yes, with Tiptap extensions via the `extensions` option. Anything outside the whitelist is dropped, so also add its tags and attributes via `sanitize`, and to your server whitelist. See [Custom extensions](/guide/security#custom-extensions).

### What happens to content pasted from Word or Google Docs?

It is cleaned: styles, classes, and unknown tags are removed, but bold and italic set through styles are kept as `<b>` and `<i>`.

## Images

### Where are images stored?

Without the `upload` option, images are embedded as base64 inside the HTML. That is fine for a quick test, but in production provide an [upload function](/guide/images-video#upload-to-a-server) that sends the file to your server or storage (S3, R2, …) and returns its URL.

### Can I use images from my CMS media library?

Yes. Set `imageRequest: true` and listen for `wysiwyg-image-request` to open your own gallery, then call `insert({ src, mediaId })`. See [Choosing from your app's gallery](/guide/images-video#choosing-from-your-apps-gallery).

### How do I swap an image without losing its caption?

Click the image and choose **Replace image** in the media toolbar. The caption, size, and position stay, and one undo brings the old image back. With `imageRequest: true` your gallery opens with `mode: 'replace'`. See [Replacing an image](/guide/images-video#replacing-an-image).

### Which formats are supported? What about SVG?

PNG, JPG, GIF, WebP, and AVIF. SVG is rejected because it can carry scripts. The default size limit is 5 MB (`maxImageSize`, `0` = no limit).

### Which videos can be embedded?

YouTube and Vimeo. The iframe `src` is always rebuilt from the video ID, so other sites can't be embedded through it.

## Editing

### Can I hide the top toolbar, like Medium?

Yes: `toolbar: false`. Formatting stays available through the bubble, the `/` menu, the `+` button, keyboard shortcuts, and markdown. See [Usage](/getting-started/usage#medium-style-no-top-toolbar).

### Is there a read-only mode?

Yes: the `readonly` option, or `setReadOnly(true)` at runtime.

### Can the UI be in another language?

English is the default and Indonesian (`lang: 'id'`) is built in. Any label can be overridden with `strings`. See [Language](/guide/appearance#language).

### Does it have a dark theme?

Yes: `data-afw-theme="dark"` or `"auto"`, or a `.dark` class on `<html>` as in Tailwind. See [Dark theme](/guide/appearance#dark-theme).

### Will drafts survive a closed tab?

With `autosave: 'post-42'`, the draft is kept in localStorage and a **Restore / Discard** banner appears when the page is opened again. See [Autosave](/guide/autosave).
