## Di dalam form

```html
<form method="post">
  <div x-data="wysiwyg({ name: 'body', upload: uploadImage })">
    <p>Konten awal (opsional)</p>
  </div>
  <button>Simpan</button>
</form>
```

Markup UI (toolbar, bubble, menu) dibuat otomatis. Isi elemen menjadi konten awal, dan `name` membuat `<input type="hidden">` berisi HTML yang ikut terkirim bersama form.

## Dengan x-model

```html
<div x-data="{ body: '' }">
  <div x-data="wysiwyg()" x-modelable="html" x-model="body"></div>
  <p x-text="body.length + ' karakter'"></p>
</div>
```

## Ala Medium (tanpa toolbar atas)

```html
<div x-data="wysiwyg({ name: 'body', toolbar: false, stats: false })"></div>
```

Format tetap tersedia lewat bubble (blok teks), slash menu, tombol `+`, shortcut keyboard, dan markdown.

## Menampilkan hasil

Pakai class `afw-prose` agar tipografi hasil sama dengan di editor:

```blade
<article class="afw-prose">{!! $post->body !!}</article>
```

::warning
Cetak HTML mentah (`{!! !!}`) **hanya** setelah disanitasi di server. Lihat [Keamanan](/panduan/keamanan).
::

## Menangkap perubahan

Event dikirim dari elemen editor dan *bubbling*:

```html
<div x-data="wysiwyg()" @wysiwyg-change="console.log($event.detail.html)"></div>
```

Daftar lengkap ada di [Event & API](/panduan/event-api).
