**:brand** adalah editor teks kaya (WYSIWYG) bergaya Medium untuk proyek berbasis **Alpine.js**, terutama Laravel. Cukup satu atribut `x-data`, editor lengkap dengan toolbar, bubble, dan slash menu langsung tampil, dan isinya ikut terkirim bersama form.

## Fitur utama

- **Bubble toolbar** saat teks diblok, **slash command** `/`, dan tombol `+` di baris kosong
- **Shortcut markdown**: `##`, `>`, `-`, `1.`, `---`, ```` ``` ````, `**tebal**`, `*miring*`, `` `kode` ``
- **Gambar** (upload, keterangan, alt text, tiga ukuran), **video** YouTube/Vimeo, pemisah, blok kode
- **Judul H2–H6** yang bisa diatur sesuai kebutuhan
- Output **HTML** yang selalu disanitasi, atau **JSON** dokumen ProseMirror
- **Autosave** draf ke localStorage
- Undo/redo, mode baca saja, `x-model`, bahasa Indonesia & Inggris
- CSS dengan prefix `afw`, aman bersama Bootstrap, Tailwind, dan framework lain
- Integrasi **Laravel** siap pakai: komponen Blade, upload, sanitasi server, Livewire

## Cara kerja

:brand terdiri dari tiga lapis:

| Lapis | Isi |
|---|---|
| **Engine** | [Tiptap](https://tiptap.dev) / [ProseMirror](https://prosemirror.net): dokumen disimpan sebagai data, bukan HTML buatan browser, sehingga perilaku mengetik sama di semua browser |
| **Inti editor** (`Editor`) | Perintah, sanitasi, media, markdown, autosave. Bisa dipakai tanpa Alpine |
| **Komponen Alpine** (`wysiwyg`) | UI: toolbar, bubble, slash menu, toolbar media, input link, toast |

::note
Isi editor selalu melewati **whitelist sanitasi**, baik saat dimuat, saat paste, maupun saat diambil sebagai output. Hanya tag dan atribut yang dikenal editor yang tersisa.
::
