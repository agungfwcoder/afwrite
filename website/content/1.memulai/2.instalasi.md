Ada dua cara: lewat **bundler** (Vite, termasuk Vite bawaan Laravel) atau langsung dari **CDN** tanpa build sama sekali. Keduanya butuh **Alpine.js 3** untuk komponen UI.

## Lewat CDN (tanpa build)

Cukup tempel di `<head>`. Script :brand harus dimuat **sebelum** Alpine:

```html [index.html]
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/agungfwcoder/afwrite@v2.1.0/dist/afwrite.css">
<script defer src="https://cdn.jsdelivr.net/gh/agungfwcoder/afwrite@v2.1.0/dist/afwrite.min.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3/dist/cdn.min.js"></script>
```

Lalu pakai di halaman:

```html
<form method="post">
  <div x-data="wysiwyg({ name: 'body' })"><p>Konten awal</p></div>
  <button>Simpan</button>
</form>
```

File CDN sudah berisi Tiptap/ProseMirror (±130 KB gzip). Plugin terdaftar otomatis, dan API lain (`Editor`, `sanitize`, `toJSON`, …) tersedia di `window.Afwrite`. Ganti `v2.1.0` dengan versi yang diinginkan; lihat [catatan rilis](/lainnya/changelog).

::note
Jika Alpine sudah dimuat lewat `<script>` lain di halaman, cukup tambahkan CSS dan `afwrite.min.js` sebelum script Alpine itu. Untuk Livewire, pakai cara bundler di [Integrasi Livewire](/integrasi/livewire).
::

## Lewat bundler

::steps{level="3"}

### Pasang paket

Pasang langsung dari GitHub:

```bash [Terminal]
npm install github:agungfwcoder/afwrite#v2.1.0 alpinejs
```

Tiptap/ProseMirror ikut terpasang sebagai dependency. Setelah :brand dipublish ke npm, cukup `npm install afwrite alpinejs`.

### Daftarkan plugin

```js [resources/js/app.js]
import Alpine from 'alpinejs'
import afwrite from 'afwrite'
import 'afwrite/style.css'

Alpine.plugin(afwrite)
window.Alpine = Alpine
Alpine.start()
```

### Pakai di halaman

```html
<div x-data="wysiwyg({ name: 'body' })">
  <p>Konten awal (opsional)</p>
</div>
```

::

## Ukuran

| Bagian | gzip |
|---|---|
| Kode :brand | ±25 KB |
| Tiptap + ProseMirror | ±110 KB |
| **Total di aplikasi** | **±135 KB** |

::tip
Jika editor hanya dipakai di sebagian halaman (mis. panel admin), muat secara dinamis agar halaman lain tidak ikut membawa editor:

```js
if (document.querySelector('[x-data*="wysiwyg("]')) {
  const { default: afwrite } = await import('afwrite')
  await import('afwrite/style.css')
  Alpine.plugin(afwrite)
}
```
::

## Memuat CSS tanpa kedipan

Komponen editor disembunyikan otomatis sampai Alpine selesai menyiapkannya, sehingga isi mentah tidak sempat tampil. Pastikan CSS dimuat di `<head>` (di Laravel, `@vite` sudah melakukannya pada build produksi).
