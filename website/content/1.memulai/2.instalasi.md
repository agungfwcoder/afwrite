## Kebutuhan

- Bundler modul ES, misalnya **Vite** (termasuk Vite bawaan Laravel)
- **Alpine.js 3** (untuk komponen UI; inti editor bisa dipakai tanpa Alpine)

## Pasang

::steps{level="3"}

### Pasang paket

:brand bisa dipasang langsung dari repo git (termasuk repo private):

```bash [Terminal]
npm install git+ssh://git@github.com/agungfwibowo/afwrite.git#v2.0.0 alpinejs
```

Tiptap/ProseMirror ikut terpasang sebagai dependency.

### Daftarkan plugin

```js [resources/js/app.js]
import Alpine from 'alpinejs'
import wyswyg from 'wyswyg'
import 'wyswyg/style.css'

Alpine.plugin(wyswyg)
window.Alpine = Alpine
Alpine.start()
```

### Pakai di halaman

```html
<div x-data="wysiwyg({ name: 'body' })">
  <p>Konten awal (opsional)</p>
</div>
```

::

## Ukuran

| Bagian | gzip |

| Kode :brand | ±25 KB |

::tip
Jika editor hanya dipakai di sebagian halaman (mis. panel admin), muat secara dinamis agar halaman lain tidak ikut membawa editor:

```js
if (document.querySelector('[x-data*="wysiwyg("]')) {
  const { default: wyswyg } = await import('wyswyg')
  await import('wyswyg/style.css')
  Alpine.plugin(wyswyg)
}
```
::

## Memuat CSS tanpa kedipan

Komponen editor disembunyikan otomatis sampai Alpine selesai menyiapkannya, sehingga isi mentah tidak sempat tampil. Pastikan CSS dimuat di `<head>` (di Laravel, `@vite` sudah melakukannya pada build produksi).
