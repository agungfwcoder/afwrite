## Lengkap

Toolbar atas, bubble, slash menu, statistik kata, dan autosave bawaan.

::editor-demo
---
content: |
  <h2>Selamat datang 👋</h2>
  <p>Coba <b>blok teks ini</b> untuk memunculkan bubble toolbar, atau taruh kursor di <a href="https://example.com">link ini</a>.</p>
  <blockquote>Tulisan yang baik dimulai dari editor yang tidak mengganggu.</blockquote>
  <p>Shortcut markdown yang bisa dicoba:</p>
  <ul><li>ketik ## lalu spasi untuk judul</li><li>ketik &gt; lalu spasi untuk kutipan</li><li>ketik **tebal** atau `kode`</li><li>ketik ``` lalu spasi untuk blok kode</li><li>ketik / di baris kosong untuk memilih blok</li></ul>
  <p>Seret file gambar ke sini, tempel screenshot, atau tempel link YouTube di baris kosong.</p>
---
::

## Ala Medium

Mode artikel (`title: true`) tanpa toolbar atas. Baris pertama judul; blok baris di bawahnya lalu pilih tombol judul kecil untuk subjudul.

::editor-demo
---
options:
  title: true
  toolbar: false
  stats: false
  placeholder: Ceritakan kisahmu…
---
::

## Judul H2–H6

Opsi `headings: [2, 3, 4, 5, 6]`: semua level judul muncul di toolbar dan slash menu.

::editor-demo
---
options:
  headings: [2, 3, 4, 5, 6]
  stats: false
content: |
  <h2>Judul 2</h2><h3>Judul 3</h3><h4>Judul 4</h4><h5>Judul 5</h5><h6>Judul 6</h6>
  <p>Ketik #### lalu spasi untuk judul level 4.</p>
---
::
