::code-group

```html [Alpine]
<div x-data="wysiwyg({ name: 'body', lang: 'id', headings: [2, 3, 4], autosave: 'post-42' })"></div>
```

```js [JavaScript]
Afwrite.create('#body', { name: 'body', lang: 'id', headings: [2, 3, 4], autosave: 'post-42' })
```

::

::note
The options are identical for the Alpine component and [`create()`](/integrations/javascript) (and the [React](/integrations/react) / [Vue](/integrations/vue) wrappers' `options`). The guide pages show the Alpine form; without Alpine, pass the same object to `create()`.
::

## Form & content

::field-group
  ::field{name="name" type="string"}
  Name of the `<input type="hidden">` created for the form. Default `''` (no input).
  ::

  ::field{name="format" type="'html' | 'json'"}
  Contents of the hidden input. Default `'html'`. With `'json'`, it holds the ProseMirror document JSON (see [JSON](/guide/json)).
  ::

  ::field{name="titleName" type="string"}
  Name of an `<input type="hidden">` holding the title: the `<h1>` in article mode, otherwise the first text. Default `''` (no input). See [Title & slug](/guide/event-api#title-slug).
  ::

  ::field{name="content" type="string"}
  Initial content. Default: the editor element's HTML content.
  ::

  ::field{name="autosave" type="string | { key, delay }"}
  Save drafts to localStorage. Default `null`. See [Autosave](/guide/autosave).
  ::

  ::field{name="readonly" type="boolean"}
  Read-only mode. Default `false`.
  ::
::

## Appearance & UI

::field-group
  ::field{name="toolbar" type="boolean"}
  Top toolbar. Default `true`; `false` = bubble only (Medium-style).
  ::

  ::field{name="bubble" type="boolean"}
  Bubble toolbar when text is selected. Default `true`.
  ::

  ::field{name="stats" type="boolean"}
  Word count & reading time below the editor. Default `true`.
  ::

  ::field{name="dragHandle" type="boolean"}
  ⋮⋮ handle to the left of a block for moving (drag) or selecting (click) it. Default `true`. Only shown on devices with a mouse.
  ::

  ::field{name="toolbarItems / bubbleItems" type="array"}
  Custom button layout. See [Toolbar & menus](/guide/toolbar).
  ::

  ::field{name="title" type="boolean"}
  Medium-style article mode: an `<h1>` title + subtitle. Default `false`. See [Toolbar & menus](/guide/toolbar#article-mode-title-subtitle).
  ::

  ::field{name="headings" type="number[]"}
  Heading levels to use, `2`–`6`. Default `[2, 3]`. See [Toolbar & menus](/guide/toolbar#headings-h2h6).
  ::

  ::field{name="formats" type="string[] | false"}
  Extra formats: `'underline'`, `'strike'`, `'color'`, `'highlight'`, `'align'`. Default: all, except in article mode (`title: true`), which stays plain. `false` = no extra formats. See [Toolbar & menus](/guide/toolbar#extra-formats).
  ::

  ::field{name="colors / highlights" type="string[]"}
  Text color and highlight palettes, in hex. Colors outside the palette are dropped when content is loaded or pasted.
  ::

  ::field{name="blocks" type="array"}
  Contents of the `/` slash menu. Default: all blocks.
  ::

  ::field{name="lang" type="'en' | 'id'"}
  Interface language. Default `'en'`; `'id'` for Indonesian.
  ::

  ::field{name="strings" type="object"}
  Override some of the UI text, e.g. `{ placeholder: 'Write…' }`. The list of keys is in `src/i18n.js`.
  ::

  ::field{name="placeholder" type="string"}
  Text shown while the editor is empty. Default comes from the language.
  ::

  ::field{name="label" type="string"}
  `aria-label` of the editing area for screen readers.
  ::
::

## Behavior

::field-group
  ::field{name="markdown" type="boolean"}
  Markdown shortcuts while typing. Default `true`.
  ::

  ::field{name="slash" type="boolean"}
  Slash menu. Default `true`.
  ::

  ::field{name="pasteAsPlainText" type="boolean"}
  Strip all formatting on paste. Default `false`.
  ::

  ::field{name="historyLimit" type="number"}
  Number of undo steps. Default `100`.
  ::
::

## Images

::field-group
  ::field{name="upload" type="(file: File) => Promise<string | { url, mediaId?, alt? }>"}
  Upload function that returns the image URL, or an object with a `mediaId` (media library ID, written as `data-media-id`). Without it, images are stored as base64 in the HTML. See [Images & video](/guide/images-video#upload-to-a-server).
  ::

  ::field{name="maxImageSize" type="number"}
  Maximum image size in bytes. Default 5 MB; `0` = no limit.
  ::

  ::field{name="allowDataImages" type="boolean"}
  Allow `<img src="data:image/…">` in the output. Default `true`.
  ::

  ::field{name="imageRequest" type="boolean"}
  `true` = the `image` command fires `wysiwyg-image-request` instead of opening the file dialog, so your app can show its own gallery. Default `false`. See [Images & video](/guide/images-video#choosing-from-your-apps-gallery).
  ::
::

## Advanced

::field-group
  ::field{name="extensions" type="Extension[]"}
  Additional Tiptap extensions (your app's own nodes or marks), installed after the built-in extensions.
  ::

  ::field{name="sanitize" type="{ allowTags, allowAttributes, allowClasses }"}
  Extra whitelist for the extensions above. Without it, tags from those extensions are stripped on paste, `setHTML`, and `getHTML`. See [Security](/guide/security#custom-extensions).
  ::
::
