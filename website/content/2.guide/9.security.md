All incoming HTML (paste, drop, `setHTML`) and outgoing HTML (`getHTML`) passes through a whitelist:

| Type | Allowed |
|---|---|
| Tags | `p`, `h1` (article mode), `h2`–`h6` (per `headings`), `blockquote`, `ul`, `ol`, `li`, `b`, `i`, `a`, `code`, `br`, `pre`, `figure`, `img`, `figcaption`, `iframe`, `hr`; with [additional formats](/guide/toolbar#extra-formats) also `u`, `s`, `span`, `mark` |
| `a[href]` | http, https, mailto, tel, and relative URLs |
| `img[src alt data-media-id]` | src is validated; data URLs only for PNG/JPG/GIF/WebP/AVIF; `data-media-id` digits only |
| `class` | `afw-subtitle` (article-mode subtitle) and `afw-align-center/right/justify` on `p` & `h2`–`h6` |
| `style` | Only `color` on `span` and `background-color` on `mark`, with colors from the palette |
| `figure` | `data-size` (`wide`/`full`), `data-embed` |
| `iframe` | YouTube/Vimeo only; `src` is rebuilt from the video ID |

Pastes from Word, Google Docs, and the web are cleaned: styles, classes, and foreign tags are dropped, but bold/italic set via styles is still recognized.

::caution
**Browser-side sanitization does not replace server-side sanitization.** Requests can be sent without going through the editor, so the server must filter HTML with the same whitelist before storing or displaying it.
::

For Laravel, `WyswygHtml::clean()` based on HTMLPurifier is available. See [Laravel integration](/integrations/laravel).

## Custom extensions

App-specific nodes or marks are added via the `extensions` option. Their tags and attributes must be added to the whitelist via `sanitize`, because anything not on the whitelist is dropped:

```js
import { Mark } from '@tiptap/core'

const Sup = Mark.create({
  name: 'sup',
  parseHTML: () => [{ tag: 'sup' }],
  renderHTML: () => ['sup', 0],
})

wysiwyg({
  extensions: [Sup],
  sanitize: {
    allowTags: ['sup'],                       // extra inline tags
    allowAttributes: { a: ['target', 'rel'] }, // per tag; '*' = all tags
    allowClasses: ['note'],
  },
})
```

`on*`, `style`, and `srcdoc` attributes never pass, and `href`/`src` are still validated. Attributes or classes on built-in tags (e.g. `rel` on links) also need an extension that preserves them, for example via `addGlobalAttributes`. The server whitelist (`WyswygHtml::clean()`) needs the same rules added.

## Using `sanitize()` directly

```js
import { sanitize } from 'afwrite'

sanitize('<div style="x">Hi <script>x()</script><b>there</b></div>') // '<p>Hi <b>there</b></p>'
sanitize('<h4>Chapter</h4>', { headings: [2, 3, 4] })                 // '<h4>Chapter</h4>'
```
