---
title: Autosave
description: Save drafts to localStorage and restore them.
navigation:
  icon: i-lucide-save
---

```html
<div x-data="wysiwyg({ name: 'body', autosave: 'post-42' })"></div>
```

- The draft is saved to localStorage on every change, debounced by 1 second.
- When the page is opened again and there is a draft that differs from the current content, a **Restore / Discard** banner appears. Until one is chosen, the old draft is not overwritten.
- The draft is cleared automatically when its parent form is submitted.

Use a unique key per document, e.g. `post-{{ $post->id }}`, so drafts don't get mixed up.

## Setting the delay

```js
wysiwyg({ autosave: { key: 'post-42', delay: 3000 } })
```

## Via the API

```js
editor.draft          // { html, time } or null
editor.restoreDraft()
editor.discardDraft()
editor.clearDraft()   // e.g. after a successful AJAX save
```

::note
If localStorage is unavailable (private mode, quota exceeded), autosave is silently disabled without errors.
::
