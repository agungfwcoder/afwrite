## Headings H2–H6

By default the editor uses **H2** and **H3**, shown as a large **T** and a small **t** button like Medium (this applies whenever exactly two levels are active; three or more levels use H2, H3, … icons). Enable other levels with `headings`:

```html
<div x-data="wysiwyg({ headings: [2, 3, 4, 5, 6] })"></div>
```

This option automatically configures:

| Part | Behavior |
|---|---|
| Toolbar | A button for each active level |
| Bubble | At most the first 2 levels, to keep it compact |
| Slash menu `/` | An item for each active level |
| Shortcut | Ctrl/⌘ + Alt + 2 … 6 (active levels only) |
| Markdown | `## ` … `###### ` followed by a space |
| Paste & existing content | Inactive levels are mapped to the nearest active level (H1 becomes the smallest level) |

::editor-demo
---
options:
  headings: [2, 3, 4, 5, 6]
  stats: false
content: |
  <h2>Judul 2</h2><h3>Judul 3</h3><h4>Judul 4</h4><h5>Judul 5</h5><h6>Judul 6</h6>
---
::

::note
Example mapping with `headings: [2, 4]`: H3 becomes H2, H5 and H6 become H4.
::

## Extra formats

**Full** mode (toolbar) and **Simple** mode (`toolbar: false`) include the following formats. Article mode (`title: true`) does not, so it stays plain like Medium.

| Format | Button | Shortcut | Output |
|---|---|---|---|
| Underline | toolbar & bubble | Ctrl/⌘ + U | `<u>` |
| Strikethrough | toolbar | Ctrl/⌘ + Shift + X | `<s>` |
| Text color | **Color & highlight** palette | | `<span style="color: #e11d48">` |
| Highlight | **Color & highlight** palette | | `<mark style="background-color: #fef08a">` |
| Alignment | **Alignment** palette | Ctrl/⌘ + Shift + L / E / R / J | `<p class="afw-align-center">` (also `right`, `justify`) |

::editor-demo
---
options:
  stats: false
content: |
  <h2 class="afw-align-center">Judul di tengah</h2>
  <p>Teks <u>bergaris bawah</u>, <s>dicoret</s>, <span style="color: #e11d48">merah</span>, dan <mark style="background-color: #fef08a">distabilo</mark>.</p>
  <p class="afw-align-right">Paragraf rata kanan.</p>
---
::

- Colors come only from the palette (the `colors` and `highlights` options) and are always written as hex, so the HTML before saving and after reloading is identical. Colors outside the palette are dropped; highlights outside the palette become a plain `<mark>`.
- Alignment applies to top-level paragraphs and headings, not to list items or quotes. Left alignment = no class.
- Existing content is recognized too: `ql-align-*` (Quill), `style="text-align: …"`, the `align` attribute, `<strike>`, `<del>`, `<ins>`, `<font color>`, and `<mark data-color>`.
- Enable only some: `formats: ['underline', 'align']`, or `formats: false` to turn them all off. Buttons for inactive formats are hidden, including in custom `toolbarItems`/`bubbleItems`.

```js
wysiwyg({
  formats: ['underline', 'color', 'align'],
  colors: ['#e11d48', '#2563eb', '#16a34a'],
})
```

::note
On public pages, `.afw-prose` already includes styles for `afw-align-*`, `<u>`, `<s>`, and `<mark>`.
::

## Article mode (title & subtitle)

Like the Medium editor: the topmost text is always the **title**, and the line right below it can become a **subtitle**. Only images, videos, or dividers may sit above the title; the first image becomes the **feature image**.

```html
<div x-data="wysiwyg({ name: 'body', title: true, toolbar: false })"></div>
```

::editor-demo
---
options:
  title: true
  toolbar: false
  stats: false
---
::

- The **title** (`<h1>`) is always on the first line and holds plain text. Enter moves to the line below it.
- Create a **subtitle** by choosing the **small** heading button (the second level, e.g. H3) in the bubble or toolbar on the line right after the title, or via `/subheading`. Choose it again to turn it back into a paragraph. On any other line, the same button still creates a regular section heading.
- Bold, italic, lists, and code don't apply to the title/subtitle; their buttons are dimmed. Links still work in the subtitle.
- [Extra formats](#extra-formats) (underline, color, alignment) are off in article mode. Enable them manually with `formats` if you really need them.
- **Title / Subtitle** labels appear in the left margin once the title/subtitle has text, if the editor is wide enough (≥ 640px).
- Pasting several lines into the title: the first line becomes the title, the rest becomes body content below it.
- **Above the title**: click `+` (or type `/`) in an empty title and choose Image, Video, or Divider, or paste / drop an image onto the title. The block is inserted right above the title and the cursor stays in the title. You can add more than one; text can't go above the title.

HTML output:

```html
<figure><img src="cover.jpg" alt=""></figure>  <!-- optional: image/video/divider above the title -->
<h1>Post title</h1>
<p class="afw-subtitle">Optional subtitle</p>
<p>Post body…</p>
```

Content without a leading `<h1>` still loads safely: an empty title is added and the existing content doesn't shift. Images/videos/dividers at the start of the content stay above the title only if they are immediately followed by an `<h1>`.

For preview cards / meta tags, `getMeta()` extracts data like a Medium story preview:

```js
editor.getMeta()
// { image: { src, alt, caption, mediaId } | null, title: 'Post title', subtitle: 'Optional subtitle', slug }
```

`title` = first text, `subtitle` = second text (the subtitle, or the first paragraph if there is none), `image` = first image. Also works outside article mode.

::tip
You can give the title a different font, e.g. a serif like Medium: `.afw, .afw-prose { --afw-font-title: Georgia, serif; }`
::

## Custom button layout

`toolbarItems` and `bubbleItems` hold **groups** of buttons; each group is separated by a thin divider.

```js
wysiwyg({
  toolbarItems: [
    [{ command: 'bold', shortcut: '⌘B' }, { command: 'italic', shortcut: '⌘I' }],
    [{ command: 'h2', shortcut: '⌘⌥2' }, { command: 'h4', shortcut: '⌘⌥4' }],
    [{ command: 'ul', shortcut: '⌘⇧8' }],
  ],
  headings: [2, 4],
})
```

`command` is a command name from [Commands & shortcuts](/guide/commands); `shortcut` is only hint text in the tooltip.

::warning
Heading buttons only work for levels that are active in `headings`.
::

The `color` and `align` buttons open a palette (color & highlight, alignment) instead of running a command directly.

To use the default layout with different heading levels, use the `withHeadings` helper:

```js
import { TOOLBAR, BUBBLE, withHeadings } from 'afwrite'

wysiwyg({
  headings: [2, 3, 4],
  toolbarItems: withHeadings(TOOLBAR, [2, 3, 4]),
  bubbleItems: withHeadings(BUBBLE, [2, 3]),
})
```

## Slash menu

`blocks` controls the contents of the slash menu. Example without video and code blocks:

```js
import { BLOCKS } from 'afwrite'

wysiwyg({ blocks: BLOCKS.filter((b) => !['embed', 'codeblock'].includes(b.command)) })
```

## Hiding UI

| Option | Effect |
|---|---|
| `toolbar: false` | No top toolbar (Medium-style) |
| `bubble: false` | No bubble when text is selected |
| `slash: false` | No slash menu |
| `stats: false` | No word count |
