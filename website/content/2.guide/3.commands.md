Commands run through `exec(name, ...args)` and are also used by the toolbar buttons:

```html
<button @click="exec('bold')">Bold</button>
```

## Command list

| Command | Shortcut | Markdown |
|---|---|---|
| `bold` / `italic` | Ctrl/⌘ + B / I | `**text**` / `*text*` or `_text_` |
| `underline` / `strike` | Ctrl/⌘ + U / Ctrl/⌘ + Shift + X | |
| `color` / `highlight` | palette in toolbar & bubble | |
| `alignLeft` / `alignCenter` / `alignRight` / `alignJustify` | Ctrl/⌘ + Shift + L / E / R / J | |
| `link` | Ctrl/⌘ + K | paste a URL over selected text |
| `unlink` | | |
| `h2` … `h6` | Ctrl/⌘ + Alt + 2 … 6 | `## ` … `###### ` (level must be active in `headings`) |
| `paragraph` | Ctrl/⌘ + Alt + 0 | |
| `quote` | Ctrl/⌘ + Shift + 9 | `> ` |
| `ul` / `ol` | Ctrl/⌘ + Shift + 8 / 7 | `- ` / `1. ` |
| `indent` / `outdent` | Tab / Shift + Tab (inside a list) | |
| `codeblock` | Ctrl/⌘ + Alt + C | ```` ``` ```` + space, `/code` |
| `image` | | `/image`, drop a file, paste a screenshot |
| `embed` | | `/video`, paste a YouTube link on an empty line |
| `hr` | | `--- ` |
| `undo` / `redo` | Ctrl/⌘ + Z / Ctrl/⌘ + Shift + Z (or Ctrl + Y) | |
| move block | Ctrl/⌘ + Shift + ↑ / ↓ | drag the ⋮⋮ handle |

`` `code` `` (inline code) is created via markdown. Extra format commands only work when the format is enabled (the `formats` option; off in article mode).

The slash menu also matches Indonesian keywords such as `/gambar`, `/kode`, and `/pemisah`.

::tip
Markdown block shortcuts (`##`, `>`, `-`, …) only work at the start of a regular paragraph, not inside a list or quote.
::

## Command arguments

```js
editor.exec('link', 'https://example.com') // no argument: the UI asks for a URL
editor.exec('embed', 'https://youtu.be/dQw4w9WgXcQ')
editor.exec('image', fileList)              // no argument: file picker dialog
editor.exec('color', '#e11d48')             // color from the palette; no argument = remove color
editor.exec('highlight', '#fef08a')         // highlight from the palette; no argument = remove
editor.exec('align', 'center')              // left | center | right | justify; no argument = cycle
```

Link URLs are validated: `example.com` becomes `https://example.com`, while `javascript:` and `data:` are rejected.

## Moving blocks

Hover over a block: a **⋮⋮** handle appears to its left (in place of the `+` button, which only appears on empty lines).

- **Drag** the handle to move the block; a marker line shows where it will drop. A single Ctrl/⌘ + Z undoes it.
- **Click** the handle to select the whole block, then press Backspace to delete it or Ctrl/⌘ + C to copy it.
- **Ctrl/⌘ + Shift + ↑ / ↓** moves the block containing the cursor.

Only top-level blocks are moved (paragraphs, headings, quotes, whole lists, code, images, videos, dividers). In [article mode](/guide/toolbar#article-mode-title-subtitle), the title and subtitle stay in place.

```js
editor.moveBlock(-1)   // up; 1 = down
editor.selectBlock(pos)
```

## Keyboard in special blocks

**Code block**: Enter = new line, Tab / Shift + Tab = indent, Enter on the last empty line = exit the block, paste is always plain text.

**Selected image, video, or divider**: Backspace/Delete removes it, Enter creates a new paragraph below it, arrow keys move out of the media.

**Image caption**: Enter moves to the paragraph after the image.

**Empty heading or quote**: Enter turns it back into a paragraph.
