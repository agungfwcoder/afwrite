Besides HTML, editor content can be saved as JSON in the ProseMirror/Tiptap document format, so tools from the same ecosystem can read it.

```js
editor.getJSON()
// { type: 'doc', content: [
//   { type: 'heading', attrs: { level: 2 }, content: [{ type: 'text', text: 'Title' }] },
//   { type: 'paragraph', content: [
//     { type: 'text', text: 'Hello ' },
//     { type: 'text', marks: [{ type: 'bold' }], text: 'world' } ] } ] }

editor.setJSON(doc)
```

## In a form

```html
<div x-data="wysiwyg({ name: 'body', format: 'json' })"></div>
```

The hidden `body` input contains a JSON string.

## Structure

| Node | Description |
|---|---|
| `paragraph`, `heading` (`attrs.level`), `blockquote` | Text blocks |
| `bulletList`, `orderedList`, `listItem` | Lists (items contain `paragraph` and nested lists) |
| `codeBlock` | Code block |
| `horizontalRule` | Divider |
| `image` (`src`, `alt`, `size`) | Image; its content is the caption text |
| `embed` (`provider`, `id`, `size`) | YouTube/Vimeo video |
| `hardBreak`, `text` | Inline |

Marks: `bold`, `italic`, `code`, `link` (`attrs.href`).

## Without an editor

```js
import { toJSON, fromJSON } from 'afwrite'

toJSON('<p>Hello</p>', { headings: [2, 3, 4] })
fromJSON(doc, { headings: [2, 3, 4] })
```

`fromJSON` drops unknown nodes/marks and always sanitizes the result, so JSON from untrusted sources stays safe.

::warning
The v1 JSON format (`blocks` + `marks` ranges) is no longer supported since v2. The HTML format is unchanged.
::
