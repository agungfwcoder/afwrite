**:brand** is a Medium-style rich text (WYSIWYG) editor for **Alpine.js** projects, especially Laravel, and for **plain JavaScript**, React, or Vue. A single `x-data` attribute (or one `create()` call) gives you a full editor with a toolbar, bubble menu, and slash menu, and its content is submitted along with your form.

## Key features

- **Bubble toolbar** on text selection, **slash commands** `/`, and a `+` button on empty lines
- **Markdown shortcuts**: `##`, `>`, `-`, `1.`, `---`, ```` ``` ````, `**bold**`, `*italic*`, `` `code` ``
- **Images** (upload, replace in place, caption, alt text, three sizes), YouTube/Vimeo **video**, dividers, code blocks
- Configurable **H2–H6 headings**
- Always-sanitized **HTML** output, or a ProseMirror **JSON** document
- Draft **autosave** to localStorage
- Undo/redo, read-only mode, `x-model`, English & Indonesian UI
- Works **without Alpine**: [plain JavaScript](/integrations/javascript), [React](/integrations/react), [Vue](/integrations/vue)
- `afw`-prefixed CSS, safe alongside Bootstrap, Tailwind, and other frameworks
- Ready-made **Laravel** integration: Blade component, uploads, server-side sanitization, Livewire

## How it works

:brand has three layers:

| Layer | Contents |
|---|---|
| **Engine** | [Tiptap](https://tiptap.dev) / [ProseMirror](https://prosemirror.net): the document is stored as data, not browser-generated HTML, so typing behaves the same in every browser |
| **Editor core** (`Editor`) | Commands, sanitization, media, markdown, autosave |
| **UI** (`create()`) | Toolbar, bubble, slash menu, media toolbar, link input, palette, toast. Plain JavaScript, no framework |
| **Alpine component** (`wysiwyg`) | A thin adapter over `create()`: `x-data`, `x-model`, `$wire.entangle` |

::note
Editor content always passes through a **sanitization whitelist**: on load, on paste, and when read as output. Only tags and attributes the editor knows are kept.
::
