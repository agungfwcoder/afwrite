Alpine.js is **optional**: use `x-data="wysiwyg()"` with Alpine 3, or [`create()`](/integrations/javascript) without it (plain JavaScript, [React](/integrations/react), [Vue](/integrations/vue)).

## Via CDN (no build)

Paste this into `<head>`. With Alpine, the :brand script must load **before** Alpine:

```html [index.html]
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/agungfwcoder/afwrite@2/dist/afwrite.css">
<script defer src="https://cdn.jsdelivr.net/gh/agungfwcoder/afwrite@2/dist/afwrite.min.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3/dist/cdn.min.js"></script>
```

Then use it on the page:

```html
<form method="post">
  <div x-data="wysiwyg({ name: 'body' })"><p>Initial content</p></div>
  <button>Save</button>
</form>
```

Without Alpine, leave out the Alpine script and call `Afwrite.create(el, options)`; see [JavaScript (no Alpine)](/integrations/javascript).

The CDN file already bundles Tiptap/ProseMirror (~135 KB gzip). The plugin registers itself, and the rest of the API (`Editor`, `sanitize`, `toJSON`, …) is available on `window.Afwrite`. `@2` always resolves to the latest v2; see the [release notes](/more/changelog).

::note
If Alpine is already loaded by another `<script>` on the page, just add the CSS and `afwrite.min.js` before that Alpine script. For Livewire, use the bundler setup described in [Livewire integration](/integrations/livewire).
::

## Via a bundler

::steps{level="3"}

### Install the package

Install directly from GitHub:

```bash [Terminal]
npm install github:agungfwcoder/afwrite#semver:^2 alpinejs
```

Tiptap/ProseMirror are installed as dependencies. Leave out `alpinejs` if you use [`create()`](/integrations/javascript) instead. Once :brand is published to npm, `npm install afwrite alpinejs` will be enough.

### Register the plugin

```js [resources/js/app.js]
import Alpine from 'alpinejs'
import afwrite from 'afwrite'
import 'afwrite/style.css'

Alpine.plugin(afwrite)
window.Alpine = Alpine
Alpine.start()
```

### Use it on a page

```html
<div x-data="wysiwyg({ name: 'body' })">
  <p>Initial content (optional)</p>
</div>
```

::

## Size

| Part | gzip |
|---|---|
| :brand code | ~37 KB |
| Tiptap + ProseMirror | ~100 KB |
| **Total in your app** | **~135 KB** |

::tip
If the editor is only used on some pages (e.g. an admin panel), load it dynamically so other pages don't ship the editor:

```js
if (document.querySelector('[x-data*="wysiwyg("]')) {
  const { default: afwrite } = await import('afwrite')
  await import('afwrite/style.css')
  Alpine.plugin(afwrite)
}
```
::

## Loading CSS without a flash

The Alpine component is hidden automatically until Alpine has finished setting it up, so raw content never flashes on screen. With `create()`, call it right after the element (it runs synchronously). Make sure the CSS is loaded in `<head>` (in Laravel, `@vite` already does this in production builds).
