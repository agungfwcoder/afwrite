## Perintah

```bash [Terminal]
npm install
npm run dev            # demo di http://localhost:5173
npm run build          # dist/
npm test               # unit test (Vitest)

npx playwright install chromium firefox webkit   # sekali saja
npm run test:browser                             # test browser di Chromium
npm run test:browser -- all                      # Chromium, Firefox, WebKit
```

Integrasi Laravel: `php artisan test --filter=WyswygTest` di proyek Laravel yang sudah memuat file dari `integrations/laravel`.

## Situs dokumentasi

Situs ini ada di folder `website/` (Nuxt UI Docs). Demo di dalamnya memakai source library langsung dari `src/`, jadi perubahan library langsung terlihat.

```bash [Terminal]
cd website
npm install
npm run dev            # http://localhost:3000
```

Halaman ditulis dalam Markdown di `website/content/`. Editor yang bisa dicoba disisipkan dengan komponen `editor-demo`:

```mdc
::editor-demo
---
options:
  headings: [2, 3, 4]
content: |
  <h2>Judul</h2><p>Isi awal</p>
---
::
```

## Struktur repo

```
src/
  core/        inti editor tanpa Alpine (engine Tiptap: schema, perintah, sanitasi, media, markdown)
  alpine.js    komponen Alpine: bubble, slash menu, toolbar media, input link
  template.js  markup UI default
  i18n.js      teks bahasa Indonesia & Inggris
  icons.js     ikon dan susunan toolbar bawaan
  style.css    seluruh CSS (prefix afw)
demo/          halaman demo
integrations/  integrasi Laravel (Blade, upload, sanitasi server)
tests/         unit test (Vitest) & test browser (Playwright)
website/       situs dokumentasi (Nuxt)
```
