File integrasi ada di folder `integrations/laravel` repo :brand. Salin ke proyek Laravel Anda dengan struktur folder yang sama:

| File | Isi |
|---|---|
| `app/Support/WyswygHtml.php` | Sanitasi HTML di server, whitelist sama dengan editor |
| `app/Http/Controllers/WyswygUploadController.php` | Upload gambar dari editor |
| `resources/views/components/wysiwyg.blade.php` | Komponen `<x-wysiwyg>` |
| `resources/js/wyswyg.js` | Setup Alpine + fungsi upload dengan token CSRF |
| `tests/Feature/WyswygTest.php` | Feature test untuk ketiganya |

Diuji dengan Laravel 13 dan `ezyang/htmlpurifier`.

::steps{level="2"}

## Pasang

```bash [Terminal]
npm install git+ssh://git@github.com/USERNAME/wyswyg.git#v2.0.0 alpinejs
composer require ezyang/htmlpurifier
php artisan storage:link
```

Isi `resources/js/app.js` dengan `resources/js/wyswyg.js` (atau impor file itu), lalu pastikan layout memuat token CSRF:

```blade [layouts/app.blade.php]
<meta name="csrf-token" content="{{ csrf_token() }}">
@vite(['resources/css/app.css', 'resources/js/app.js'])
```

## Route upload

```php [routes/web.php]
use App\Http\Controllers\WyswygUploadController;

Route::post('/wyswyg/upload', WyswygUploadController::class)
    ->middleware('auth')
    ->name('wyswyg.upload');
```

Controller hanya menerima PNG, JPG, GIF, WebP, dan AVIF (SVG ditolak), menyimpannya di disk `public`, lalu mengembalikan `{ "url": "..." }`.

## Form

```blade
<form method="POST" action="{{ route('posts.update', $post) }}">
    @csrf
    @method('PUT')

    <x-wysiwyg
        name="body"
        :value="$post->body"
        upload-url="{{ route('wyswyg.upload') }}"
        autosave="post-{{ $post->id }}"
        :headings="[2, 3, 4]"
    />

    <button>Simpan</button>
</form>
```

## Simpan dengan sanitasi

```php
use App\Support\WyswygHtml;

public function update(Request $request, Post $post)
{
    $data = $request->validate(['body' => ['required', 'string']]);
    $post->update(['body' => WyswygHtml::clean($data['body'])]);

    return back();
}
```

## Tampilkan

```blade
<article class="afw-prose">{!! $post->body !!}</article>
```

## Props `<x-wysiwyg>`

| Prop | Keterangan |
|---|---|
| `name` | Wajib. Nama field form |
| `value` | Isi awal; setelah validasi gagal, isi dari `old()` dipakai otomatis |
| `lang` | `id` atau `en` |
| `placeholder` | Teks saat kosong |
| `upload-url` | URL route upload |
| `autosave` | Kunci draf localStorage |
| `:toolbar="false"` | Tanpa toolbar atas |
| `:readonly="true"` | Mode baca saja |
| `format` | `html` atau `json` |
| `:headings="[2, 3, 4]"` | Level judul yang dipakai |
| `:title="true"` | Mode artikel: judul `<h1>` + subjudul |

Atribut lain (mis. `class`) diteruskan ke elemen editor. Isi awal disanitasi di server sebelum dicetak, karena HTML mentah di halaman akan dijalankan browser sebelum editor sempat menyaringnya.

::caution
Request bisa dikirim tanpa melewati editor, jadi `WyswygHtml::clean()` **wajib** dipanggil sebelum menyimpan. Hasilnya aman dicetak dengan `{!! !!}`.
::
