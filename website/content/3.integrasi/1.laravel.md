File integrasi ada di folder `integrations/laravel` repo :brand. Salin ke proyek Laravel Anda dengan struktur folder yang sama:

| File | Isi |
|---|---|
| `app/Support/WyswygHtml.php` | Sanitasi HTML di server, whitelist sama dengan editor |
| `app/Http/Controllers/WyswygUploadController.php` | Upload gambar dari editor |
| `resources/views/components/wysiwyg.blade.php` | Komponen `<x-wysiwyg>` |
| `resources/js/wyswyg.js` | Memuat afwrite + fungsi upload dengan token CSRF |
| `tests/Feature/WyswygTest.php` | Feature test untuk ketiganya |

Diuji dengan Laravel 13, Livewire 4, dan `ezyang/htmlpurifier`.

::steps{level="2"}

## Pasang

```bash [Terminal]
npm install github:agungfwcoder/afwrite#semver:^2 alpinejs
composer require ezyang/htmlpurifier
php artisan storage:link
```

Impor `resources/js/wyswyg.js` dari `resources/js/app.js`. Tanpa Livewire, jalankan Alpine sendiri:

```js [resources/js/app.js]
import Alpine from 'alpinejs'
import './wyswyg'

window.Alpine = Alpine
Alpine.start()
```

Dengan Livewire, cukup `import './wyswyg'` (lihat [Livewire](/integrasi/livewire)). Pastikan layout memuat token CSRF:

```blade [layouts/app.blade.php]
<meta name="csrf-token" content="{{ csrf_token() }}">
@vite(['resources/css/app.css', 'resources/js/app.js'])
```

## Route upload

```php [routes/web.php]
use App\Http\Controllers\WyswygUploadController;

Route::post('/wyswyg/upload', WyswygUploadController::class)
    ->middleware('auth')
    ->name('wyswyg.upload');
```

Controller hanya menerima PNG, JPG, GIF, WebP, dan AVIF (SVG ditolak), menyimpannya di disk `public`, lalu mengembalikan `{ "url": "..." }`. Jika gambar dicatat di media library, kembalikan juga `"mediaId"`: editor menyimpannya sebagai `<img data-media-id="...">`. Nama field bisa diganti, mis. `window.wyswygUpload(url, { field: 'file' })`.

## Form

```blade
<form method="POST" action="{{ route('posts.update', $post) }}">
    @csrf
    @method('PUT')

    <x-wysiwyg
        name="body"
        :value="$post->body"
        upload-url="{{ route('wyswyg.upload') }}"
        autosave="post-{{ $post->id }}"
        :headings="[2, 3, 4]"
    />

    <button>Simpan</button>
</form>
```

## Simpan dengan sanitasi

```php
use App\Support\WyswygHtml;

public function update(Request $request, Post $post)
{
    $data = $request->validate(['body' => ['required', 'string']]);
    $post->update(['body' => WyswygHtml::clean($data['body'])]);

    return back();
}
```

### Judul & slug (mode artikel)

Dengan `title-name="title"`, judul ikut terkirim sebagai field terpisah. Slug final dibuat di server, termasuk memastikan unik:

```blade
<x-wysiwyg name="body" :title="true" title-name="title" />
```

```php
use Illuminate\Support\Str;

$data = $request->validate(['title' => ['required', 'string', 'max:200'], 'body' => ['required', 'string']]);

$slug = Str::slug($data['title']) ?: Str::random(8); // judul non-Latin bisa menghasilkan slug kosong
$base = $slug;
for ($i = 2; Post::where('slug', $slug)->whereKeyNot($post->id)->exists(); $i++) {
    $slug = "{$base}-{$i}";
}
```

## Props `<x-wysiwyg>`

| Prop | Keterangan |
|---|---|
| `name` | Wajib. Nama field form |
| `value` | Isi awal; setelah validasi gagal, isi dari `old()` dipakai otomatis |
| `lang` | `id` atau `en` |
| `placeholder` | Teks saat kosong |
| `upload-url` | URL route upload |
| `autosave` | Kunci draf localStorage |
| `:toolbar="false"` | Tanpa toolbar atas |
| `:readonly="true"` | Mode baca saja |
| `format` | `html` atau `json` |
| `:headings="[2, 3, 4]"` | Level judul yang dipakai |
| `:title="true"` | Mode artikel: judul `<h1>` + subjudul |
| `:formats="['underline', 'align']"` | Format tambahan yang dipakai (bawaan semua, kecuali mode artikel); `:formats="false"` = tanpa |
| `title-name="title"` | Judul (teks pertama / `<h1>` artikel) ikut dikirim sebagai input `title` |

Atribut lain (mis. `class`) diteruskan ke elemen editor. Isi awal disanitasi di server sebelum dicetak, karena HTML mentah di halaman akan dijalankan browser sebelum editor sempat menyaringnya.

::caution
Request bisa dikirim tanpa melewati editor, jadi `WyswygHtml::clean()` **wajib** dipanggil sebelum menyimpan. Hasilnya aman dicetak dengan `{!! !!}`.
::

`WyswygHtml::clean()` mengizinkan semua output editor, termasuk format tambahan (`u`, `s`, `span[style=color]`, `mark[style=background-color]`, class `afw-align-*`) dan `img[data-media-id]`. HTMLPurifier menulis style sedikit berbeda (`color:#e11d48;`); editor menormalkannya lagi saat konten dimuat, sehingga `getHTML()` sebelum simpan dan sesudah reload tetap identik.
