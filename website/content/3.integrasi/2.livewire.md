---
title: Livewire
description: Menghubungkan editor dengan properti komponen Livewire 3.
navigation:
  icon: i-lucide-zap
---

::warning
Contoh ini belum diuji otomatis seperti integrasi Laravel lainnya.
::

```blade
<div wire:ignore x-data="{ body: $wire.entangle('body') }">
    <div x-data="wysiwyg({ upload: window.wyswygUpload('{{ route('wyswyg.upload') }}') })"
         x-modelable="html" x-model="body"></div>
</div>
```

- `wire:ignore` mencegah Livewire mengubah DOM editor saat komponen dirender ulang.
- `$wire.entangle('body')` menyinkronkan isi editor dengan properti `$body`.

Sanitasi tetap dilakukan di server:

```php
public string $body = '';

public function save(): void
{
    $this->post->update(['body' => WyswygHtml::clean($this->body)]);
}
```

::tip
Agar tidak mengirim request di setiap ketikan, gunakan `$wire.entangle('body').live` hanya jika memang dibutuhkan; tanpa `.live`, nilai dikirim bersama aksi berikutnya (mis. `save`).
::
