Diuji dengan Laravel 13 + Livewire 4: ketik, simpan, sanitasi server, reload, dan `wire:navigate` bolak-balik.

## Pasang

Livewire sudah membawa dan menjalankan Alpine sendiri. **Jangan** impor `alpinejs` atau memanggil `Alpine.start()`: dua Alpine akan bentrok. Cukup:

```js [resources/js/app.js]
import './wyswyg' // dari integrations/laravel/resources/js/wyswyg.js
```

`wyswyg.js` memuat `afwrite` beserta CSS-nya. Plugin terdaftar otomatis saat event `alpine:init`, lalu menyediakan `window.wyswygUpload`.

## Komponen

```blade [livewire/post-editor.blade.php]
<div>
    <div wire:ignore>
        <div x-data="wysiwyg({ upload: window.wyswygUpload('{{ route('wyswyg.upload') }}') })"
             x-modelable="html" x-model="$wire.body"></div>
    </div>

    <button wire:click="save">Simpan</button>
</div>
```

```php [app/Livewire/PostEditor.php]
use App\Support\WyswygHtml;

public string $body = '';

public function save(): void
{
    $this->body = WyswygHtml::clean($this->body);
    $this->post->update(['body' => $this->body]);
}
```

- `wire:ignore` mencegah Livewire mengubah DOM editor saat komponen dirender ulang.
- `x-modelable="html"` + `x-model="$wire.body"` menyinkronkan isi editor dengan properti `$body`. Nilainya dikirim bersama aksi berikutnya (mis. `save`), bukan di setiap ketikan. `$wire.entangle('body')` juga bisa dipakai.
- Setelah `save`, `$body` berisi HTML hasil HTMLPurifier yang penulisannya sedikit berbeda (mis. `color:#e11d48;`). Editor membandingkan isinya setelah dinormalisasi, jadi editor tidak dimuat ulang dan kursor tidak melompat.
- Sinkron saat submit tanpa `x-model` juga bisa: `Alpine.$data(el).getHTML()`.

## `wire:navigate`

Editor dibersihkan otomatis (`destroy()`) saat halaman ditinggalkan. Pindah halaman bolak-balik tidak meninggalkan listener atau instance ganda.
